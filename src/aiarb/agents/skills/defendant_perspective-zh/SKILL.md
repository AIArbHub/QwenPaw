# 被申请人视角案件分析

从被申请人的立场出发，系统性地识别申请人主张的薄弱点，制定四层面抗辩策略，准备反证清单，评估抗辩预期效果。

## 适用场景

- 律师接受被申请人委托，需要制定抗辩策略
- 被申请人评估自身抗辩空间和胜算
- 案件准备阶段，需要针对申请人主张逐项反驳

## 核心原则

1. **攻击导向**：优先识别申请人主张的薄弱环节
2. **分层抗辩**：从事实、法律、证据、程序四个层面全面抗辩
3. **反证充分**：每一项抗辩都要有对应的反证支撑
4. **效果量化**：评估抗辩的实际效果（全部/部分反驳）

## 分析框架

### 第一步：案件识别

调用 `identify_case_type` 确定案件类型。

### 第二步：抗辩审查

调用 `generate_review_checklist(case_type, perspective="respondent")` 获取被申请人视角的审查清单（第4部分：被申请人抗辩的审查 + 第5部分：要件事实审查）。

### 第三步：薄弱点识别

调用 `dual_perspective_analysis(case_type, materials_summary)` 获取双向分析结果。

重点关注被申请人视角部分：
- **申请人主张薄弱点**：哪些要件的证据三性可能有瑕疵
- **抗辩策略**：四层面抗辩（事实/法律/证据/程序）
- **反证清单**：每项抗辩对应的反证
- **预期效果**：抗辩空间评估

### 第四步：抗辩策略细化

按四个层面细化抗辩：

#### 事实层面
- 质量/数量异议的具体依据
- 交付/履行异议的证据

#### 法律层面
- 合同效力抗辩的法律依据
- 时效抗辩的期间计算
- 条件抗辩的未成就依据

#### 证据层面
- 证据三性异议的具体角度
- 举证责任分配的法律依据

#### 程序层面
- 仲裁管辖异议的理由
- 仲裁协议效力异议的依据

### 第五步：反证准备

对照每项抗辩，准备反证：
- 身份证明
- 答辩状
- 反驳证据
- 事实证据
- 法律依据

```
|------|---------|---------|---------|------|

## 反证清单
| 序号 | 证据名称 | 对应抗辩 | 必要性 | 说明 |

## 预期抗辩效果

1. [优先级1] — [行动] — [预计时间]

```

## 质量要求

- 薄弱点分析必须对应到具体审查要点编号
- 抗辩策略必须按四层面分类
- 反证清单必须标注对应抗辩和必要性
- 效果评估必须考虑抗辩策略数量和证据强度
