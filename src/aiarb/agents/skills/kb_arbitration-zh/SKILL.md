# 仲裁知识库检索引导

处理**仲裁、争议解决**相关问题（法条、仲裁规则、机构程序、案例、文书模板）时，遵守以下原则。

## 核心原则

1. **先检索，后作答**：凡涉及具体法条、规则条文、机构名称、期限、费用、程序步骤、文书格式等，先检索共享知识库再作答。共享知识库已并入文件检索范围，可直接用 `grep_search` / `read_file`（无需区分是否在共享库）；需要按类别精准检索时再用 `search_knowledge`。
2. **不得编造**：禁止凭印象虚构法条编号、条文内容、规则条款、期限或机构名称。检索不到时，如实说明"知识库中暂无对应内容"，并建议补充来源。
3. **标注依据**：给出结论时尽量标明出处（文件名/条文/机构），便于核对。

## 使用步骤

1. 从用户问题中提取关键词（如"仲裁协议效力""撤销裁决""CIETAC 简易程序""仲裁申请书"）。
2. 用 `grep_search(pattern=关键词)` 直接检索（检索范围已覆盖共享知识库与工作区）；或用 `search_knowledge(query=关键词)` 并可按 `scope` 限定类别：
   - `laws` — 法律
   - `rules` — 仲裁规则
   - `cases` — 案例
   - `templates` — 文书模板
3. 若命中较少，换用同义词或拆分关键词再次检索（例如"仲裁协议"→"仲裁条款""效力"）。
4. 必要时用 `read_file` 打开命中文件核对上下文，再组织答案。

## 示例

- 用户问"撤销仲裁裁决的法定情形有哪些？"→ `search_knowledge(query="撤销仲裁裁决")`，再核对具体条文。
- 用户问"仲裁申请书要写哪些内容？"→ `search_knowledge(query="仲裁申请书", scope="templates")`。

## 注意

- 本 skill 是检索引导，不替代具体检索工具（`grep_search` / `read_file` / `search_knowledge`）。
- 知识库内容以本地文件为准；若与记忆中的旧知识冲突，以知识库当前文件为准。
