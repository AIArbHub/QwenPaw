# 仲裁文书起草

按知识库模板起草仲裁文书，输出即可用的初稿。

引用与防幻觉规则见知识库 `CITATION.md`；模板见 `knowledge_base/templates/`。

## 起草流程

### 第一步：确认必备要素

起草前**先问清**，缺哪个问哪个，不要自行假设：

| 要素 | 说明 |
|---|---|
| 文书类型 | 申请书 / 答辩书 / 反请求 / 代理意见 / 程序令 / 其他 |
| 受理机构 | 决定适用哪套规则与格式 |
| 当事人 | 全称、住所地、法定代表人、代理人 |
| 请求事项 | 逐条列明，金额明确到币种与计算方式 |
| 事实与理由 | 依据的材料（需能标注出处） |
| 期限 | 是否有答辩/举证期限约束 |

**要素不全时先提问，不要编造**。尤其是金额、日期、当事人名称。

### 第二步：检索并套用模板

1. `search_knowledge(query="<文书类型>", scope="templates")` 检索模板。
2. 按模板的"必备要素"与"建议结构"组织内容。
3. 无对应模板时，说明情况并采用通用结构，同时建议补充模板。

### 第三步：起草正文

1. **请求事项**——具体、可执行，避免"依法裁决"这类空泛表述。
2. **事实部分**——按时间顺序，每句话都能追溯到材料出处。
3. **理由部分**——法律论证链条完整：证据 → 事实 → 法律依据 → 结论。
4. **法律依据**——仲裁程序事项引《仲裁法》与机构规则；司法审查阶段才引《民事诉讼法》。引用前**必须检索确认条款号与现行版本**。

### 第四步：自检（逐项通过才可交付）

**格式六项：**

- [ ] 编号体系：`一、（一）1.（1）` 层级连续、不错层
- [ ] 同级标题对齐一致，正文缩进统一
- [ ] 同一层级标题字号一致
- [ ] 称谓全文统一（不得"申请人/甲方"混用）
- [ ] 金额单位、大小写、币种表述一致，计算可复算
- [ ] 引用格式符合 `CITATION.md`

**内容四项：**

- [ ] 事实均有出处，无编造
- [ ] 法律依据条款号已核对，无误引
- [ ] 请求事项与事实理由前后一致，不脱节
- [ ] 无遗漏必备要素

## 输出

1. 文书正文（Markdown 或 DOCX，按用户要求）
2. 要素核对表（哪些已填、来自哪里）
3. 待确认事项清单（需用户补充的事实与材料）

## 质量要求

- **不编造**：当事人信息、金额、日期、条款号一律来自用户材料或检索结果。
- **不套话**：避免"综上所述，恳请贵院/贵委依法支持"堆叠，每句话要有信息量。
- **详略得当**：程序性内容简略，争议焦点与法律论证详写。
- 生成 DOCX 时保留可编辑结构，便于用户修改。

## 禁止事项

- 不凭记忆写法律条文编号
- 不假设当事人未提供的金额、日期、名称
- 不在同一文书中混用不同机构的格式要求
- 不输出未经自检的初稿
