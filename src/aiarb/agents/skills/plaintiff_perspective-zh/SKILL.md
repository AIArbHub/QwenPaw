# 申请人视角案件分析

从申请人的立场出发，系统性地评估案件优势、劣势、证据准备和胜诉概率，提供可操作的补强建议。

## 适用场景

- 律师接受申请人委托，需要快速制定诉讼/仲裁策略
- 当事人评估自身案件的胜诉可能性
- 案件准备阶段，需要梳理证据缺口

## 核心原则

1. **优势导向**：优先识别和强化申请人的优势点
2. **缺口暴露**：不回避劣势，明确指出需要补强的要素
3. **证据为王**：一切分析围绕证据的充分性和有效性
4. **概率量化**：给出基于要件的胜诉概率评估

## 分析框架

### 第一步：案件识别

调用 `identify_case_type` 确定案件类型。

### 第二步：要件检核

调用 `generate_review_checklist(case_type, perspective="applicant")` 获取申请人视角的审查清单。

对每个核心要件进行检核：
- ✅ 已有证据支撑
- ❌ 缺少证据支撑
- ⚠️ 证据可能有瑕疵

### 第三步：优势/劣势分析

调用 `dual_perspective_analysis(case_type, materials_summary)` 获取双向分析结果。

重点关注申请人视角部分：
- **优势点**：识别已有证据支撑的核心要件
- **劣势点**：识别缺少证据或证据有瑕疵的要件
- **证据清单**：对照必需/重要/辅助三级分类
- **胜诉概率**：基于核心要件覆盖率的初步评估

### 第四步：补强建议

对每个劣势点，查询补强建议模板：
- 优先级排序（1=最高 → 5=最低）
- 难度评估（简单/中等/困难）
- 预计时间

## 输出模板

```
# [案件类型] — 申请人视角分析报告

## 案件概览
- 案件类型：[类型]
- 识别置信度：[百分比]
- 核心要件数量：[数量]

## 优势分析
1. [优势点1] — [证据摘要]
2. [优势点2] — [证据摘要]

## 劣势分析
1. [劣势点1] — [缺失说明] → 补强建议：[建议]
2. [劣势点2] — [缺失说明] → 补强建议：[建议]

## 证据清单
| 序号 | 证据名称 | 必要性 | 现有/缺失 | 说明 |
|------|---------|--------|---------|------|

## 胜诉概率评估
**[高/中/中低]**（[百分比]）

## 下一步行动建议
1. [优先级1] — [行动] — [预计时间]
2. [优先级2] — [行动] — [预计时间]
```

## 质量要求

- 优势/劣势分析必须对应到具体审查要点编号
- 证据清单必须标注必要性等级
- 胜诉概率必须基于要件覆盖率计算
- 补强建议必须标注优先级和预计时间
