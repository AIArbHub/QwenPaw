# 法律智能问答系统

基于类案办案要件指南知识库的自然语言问答系统，支持5种问题类型和多轮对话，为法律从业者和当事人提供结构化法律咨询。

## 适用场景

- 当事人遇到法律问题，需要初步法律意见
- 律师助理快速查询某类案件的审查要点
- 法学院学生了解六段式审判方法论
- 法律从业者查询证据清单和办理流程

## 核心原则

1. **分类精准**：5种问题类型，确保回答切题
2. **结构化输出**：回答有固定结构，便于理解和使用
3. **上下文记忆**：多轮对话中保持案件类型和角色上下文
4. **建议追问**：每次回答后推荐3个相关追问方向

## 5种问题类型

### 1. 案件识别

**触发关键词**：是什么案件、属于什么、什么纠纷、怎么定性、属于哪种、什么案由、哪类纠纷、什么类型

**处理流程**：
- 调用 `identify_case_type(query=问题)` → 返回案件类型 + 置信度
- 输出案件类型、置信度、匹配关键词
- 建议追问：法律依据、证据清单、办理流程

**示例**：
```
用户："朋友向我借款10万元，现在借款不还，这是什么纠纷？"
→ identify_case_type(query="朋友向我借款10万元...")
→ 结果：民间借贷（33.3%），匹配关键词：借款、借贷
```

### 2. 法律依据

**触发关键词**：法律依据、法条、法律规定、根据什么法、适用法律、法律条文、法律规定了

**处理流程**：
- 从上下文或问题中识别案件类型
- 查询案件类型的核心法律依据
- 如无数据库记录，调用 `search_knowledge` 检索法条
- 建议追问：证据清单、办理流程

**示例**：
```
用户："民间借贷纠纷有什么法律依据？"
→ identify_case_type(query="民间借贷") → case_id=1
→ 查询 case_types.core_legal_basis
→ 结果：民法典第667-680条、民间借贷司法解释
```

### 3. 证据清单

**触发关键词**：证据、材料、怎么证明、需要什么、提供什么、举证、证据清单、什么材料

**处理流程**：
- 从上下文或问题中识别案件类型
- 查询 evidence_checklists（按 party_type 分组）
- 按必要性排序（必需 > 重要 > 辅助）
- 建议追问：法律依据、办理流程

**示例**：
```
用户："民间借贷需要什么证据材料？"
→ 查询 evidence_checklists WHERE case_id=1
→ 申请人证据：借条(必需)、转账记录(必需)、利息约定(重要)...
→ 被申请人证据：还款凭证(必需)、借款已还清证据(重要)...
```

### 4. 流程指导

**触发关键词**：流程、程序、怎么办理、如何办理、步骤、办案流程、怎么办

**处理流程**：
- 从上下文或问题中识别案件类型
- 查询六段式框架 + 审查要点
- 按框架部分编号排序输出
- 建议追问：法律依据、证据清单

**示例**：
```
用户："民间借贷纠纷怎么办理？"
→ 查询 case_frameworks + review_points WHERE case_id=1
→ 第2部分：立案审查
  - 主管审查：是否属于仲裁受案范围
  - 管辖审查：仲裁协议效力
  - 当事人主体审查
→ 第3部分：申请人请求的审查
  ...
```

### 5. 一般咨询

**触发关键词**：（上述关键词均不匹配时）

**处理流程**：
- 尝试从问题中识别案件类型
- 置信度 > 30%：返回案件类型信息 + 建议追问
- 置信度 ≤ 30%：返回引导提示，建议用户描述更详细的案情

**示例**：
```
用户："民间借贷的利率上限是多少？"
→ identify_case_type → 民间借贷（高置信度）
→ 返回：这可能涉及"民间借贷"纠纷
→ 建议追问：法律依据、证据清单、办理流程
```

## 多轮对话支持

### 上下文管理

通过 `context` 参数传递多轮对话上下文：

```python
# 第一轮
legal_qa_consultation(question="朋友借款不还是什么纠纷？")
→ 返回：民间借贷（case_id=1）

# 第二轮（带上下文）
legal_qa_consultation(
    question="需要什么证据？",
    context='{"case_type": "民间借贷", "case_id": 1}'
)
→ 返回：证据清单
```

### 追问建议

每次回答后推荐3个相关追问：
- 案件识别 → 法律依据 + 证据清单 + 办理流程
- 法律依据 → 证据清单 + 办理流程
- 证据清单 → 法律依据 + 办理流程
- 流程指导 → 法律依据 + 证据清单

## 调用方式

```
# 基本调用
legal_qa_consultation(question="用户的问题")

# 带上下文
legal_qa_consultation(
    question="需要什么证据？",
    context='{"case_type": "民间借贷", "case_id": 1}'
)
```

## 输出规范

1. 每个回答标注问题类型
2. 结构化输出（标题、列表、表格）
3. 结尾附3个建议追问
4. 法律声明：⚠️ 本回答仅供参考，不构成法律意见
