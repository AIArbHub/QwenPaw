# 规则库说明

本目录包含仲裁裁决书核阅 Skill 的规则库文件。

---

## 文件清单

| 文件名 | 说明 |
|--------|------|
| `format-rules.md` | 格式核阅规则库（结构化表） |
| `content-mapping.md` | 内容比对映射规则（裁决书与案件材料的比对逻辑） |
| `legal-rules.md` | 法律合规核阅规则库 |
| `changelog.md` | 规则库变更日志 |
| `README.md` | 本说明文件 |

---

## 规则分类

### 1. 格式规则（format-rules.md）
- 国内裁决书格式：29条规则，涵盖字体、字号、行间距、页边距、页码、标点、结构层次、简称、证据表述、币种标注、注释格式、合同效力表述、裁决作出表述、履行期限、逾期后果等
- 国际裁决书格式：17条规则，涵盖封面、正文、尾部的格式规范

### 2. 内容比对规则（content-mapping.md）
定义裁决书各模块与案件材料的比对关系：
- 申请人部分：事实与理由、仲裁请求
- 被申请人部分：答辩意见
- 反请求部分：反请求
- 证据部分：申请人证据、被申请人证据
- 仲裁请求覆盖性：漏裁、超裁、鉴定费、仲裁费

### 3. 法律规则（legal-rules.md）
- 国内裁决法律规则：12条规则，涵盖争议点回应、论述依据、法律条款引用、请求裁判明确性等
- 国际裁决法律规则：12条规则（与国内一致）
- 人工复核清单：需人工确认的法律实质判断事项

## 规则属性说明

每条规则包含以下属性：

| 属性 | 说明 |
|------|------|
| 规则ID | 唯一标识符，格式：DOM/INT + 类型 + 序号 |
| 问题类型 | 格式、文字、内容比对、法律 |
| 问题子类 | 具体问题分类 |
| 规则描述 | 可量化检测的规则描述 |
| 优先级 | 必须修改 / 建议修改 |
| 检测逻辑 | AI 执行检测的具体步骤 |
| 修改建议模板 | 建议的修改表述格式 |
| 规则来源 | 规则依据（文件/条款） |

## 规则迭代

当发现 AI 漏检某个问题时：

1. 告诉 AI："你漏掉了一个问题：[描述问题]"
2. AI 会将此问题整理为新规则，追加到对应规则文件中
3. 更新 `changelog.md` 记录变更

当需要新增核阅规范时：

1. 直接描述新规范："以后核阅时，[新规范描述]"
2. AI 整理后追加到规则库
3. 更新 `changelog.md` 记录变更
