# 法律合规核阅规则库

## 规则说明

本规则库涵盖法律条款引用、仲裁庭论述实质判断等方面的核阅规则。由于法律判断较为复杂，本规则库目前为"建议修改"为主，标记出需人工复核的重点事项。

## 人工复核清单（AI无法自动确认的事项）

以下事项需人工复核，AI仅提示不直接修改：

### 法律实质判断
1. 仲裁庭论述的法律依据是否充分、准确
2. 仲裁庭对事实的认定是否合理
3. 仲裁庭对争议点的回应是否充分
4. 仲裁费分担比例是否合理
5. 鉴定费负担是否合理
6. 是否存在其他法律风险

### 程序合规性
1. 程序变更是否有充分理由
2. 延长审限是否有充分理由
3. 中止和恢复程序是否符合规定
4. 管辖权异议处理是否正确

### 当事人权益保护
1. 是否存在侵害当事人权益的情形
2. 是否存在程序违法或程序瑕疵
3. 是否存在仲裁庭越权裁判
