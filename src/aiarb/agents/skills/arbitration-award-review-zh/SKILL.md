# 仲裁裁决书核阅技能

## 技能描述

本技能用于对仲裁裁决书初稿进行系统性核阅。核阅范围涵盖格式规范、文字表述、内容完整性及法律合规性。核阅结果以 Word 批注/修订形式输出，同时生成结构化核阅报告。

本技能规则库可在使用中持续迭代——每次发现 AI 漏检的问题，可通过对话告知，即时补充到规则库中。

---

## 使用场景触发词

- "帮我核阅这份裁决书"
- "审查裁决书初稿"
- "核阅裁决/裁决书"
- "检查裁决书有没有问题"
- 用户提供裁决书文件（.docx/.doc）+ 案件材料时

---

## 输入要求

### 必须提供
1. **裁决书初稿**：.docx 或 .doc 格式
2. **裁决书类型**：国内案件 / 国际案件
3. **程序类型**：简易程序 / 普通程序

### 建议同时提供（用于内容比对核阅）
按以下优先级提供案件材料，材料越完整，核阅越准确：

| 优先级 | 材料名称 | 用于核阅的模块 |
|--------|----------|----------------|
| P0 | 仲裁申请书 | 申请人主张、仲裁请求比对 |
| P0 | 庭审笔录 | 仲裁请求最终确认、答辩意见、证据清单比对 |
| P1 | 答辩书/答辩状 | 被申请人答辩意见比对 |
| P1 | 双方证据清单（PDF前几页） | 证据列举完整性核对 |
| P2 | 鉴定报告（如有） | 鉴定费裁判核对 |
| P2 | 变更仲裁请求申请书（如有） | 最终请求确认 |

## 核阅工作流程

> **核阅原则：每句话都要仔细核阅**
> **核心方法：先建立映射关系，再逐项比对**

---

### 阶段一：案件材料清单建立（前置步骤）

**目的**：明确有哪些材料可用，每份材料的用途是什么

1. **列出所有案件材料**

   遍历案件材料文件夹，按以下分类整理：

   ```
   【主体资格材料】营业执照、身份证、护照等
   → 用途：核对当事人名称、证件号码、住址

   【授权委托材料】授权委托书、法定代表人证明书
   → 用途：核对代理人姓名、职务、律所

   【程序文书】仲裁申请书、答辩书、反请求申请书等
   → 用途：核对仲裁请求、答辩意见

   【证据材料】证据清单/目录（通常在PDF前几页）、证据正文
   → 用途：核对证据编号、名称

   【庭审记录】开庭笔录
   → 用途：核对最终确认的仲裁请求、当庭提交的证据

   【程序性文件】受理通知、组庭通知等
   → 用途：核对受理日期、案件编号、组庭日期

   【补充材料】补充证据、庭后代理意见
   → 用途：核对庭后补充的证据和主张
   ```

2. **识别缺失的关键材料**
   - 如缺少主体资格材料 → 无法核阅当事人信息准确性
   - 如缺少授权委托书 → 无法核阅代理人信息准确性
   - 如缺少证据清单 → 以庭审笔录举证部分为准
   - 在核阅报告中标注缺失的材料及影响

---

### 阶段二：从案件材料文件夹全文检索提取材料

**目的**：从案件材料文件夹中提取所有核阅所需的材料内容

**操作方法**：

1. **遍历案件材料文件夹**，识别所有文件：
   ```
   - 裁决书初稿（.docx）
   - 庭审笔录（.docx）
   - 全套案件材料（PDF）
   - 补充证据（PDF）
   - 程序文书（PDF）
   - 其他材料
   ```

2. **提取文本内容**：
   - 对.docx文件：直接提取文本
   - 对.pdf文件：提取文本内容（如文件过大，提取关键页面）
   - 记录每个材料的完整路径和文件名

3. **建立材料索引**：
   ```
   | 材料名称 | 文件路径 | 文件类型 | 提取状态 | 关键内容位置 |
   |----------|----------|----------|----------|-------------|
   | 裁决书初稿 | [路径] | docx | 已提取 | 全文 |
   | 庭审笔录 | [路径] | docx | 已提取 | 全文 |
   | 全套材料 | [路径] | pdf | 已提取关键页 | 证据清单在第X页 |
   ```

**关键规则**：
- 必须先从案件材料文件夹提取所有可用材料
- 对PDF文件，优先提取：证据清单页、申请书、答辩书、身份证明等关键页面
- 记录每个信息的具体来源文件和页码位置

---

### 阶段三：逐项比对核阅

#### 3.1 首部当事人信息核阅

**比对逻辑**：
```
对于每个当事人：
  1. 提取裁决书中的信息（姓名、证件号码、住址）
  2. 从案件材料中提取对应信息（申请书、身份证明文件）
  3. 文本完全匹配 → 通过
  4. 文本不匹配 → 标记问题，注明来源

对于每个代理人：
  1. 提取裁决书中的信息（姓名、律所、职务）
  2. 从授权委托书、律师证中提取对应信息
  3. 文本完全匹配 → 通过
  4. 文本不匹配 → 标记问题
```

**特别注意**：
- 自然人：身份证号码、住址须与身份证/护照一致
- 法人：法定代表人须与营业执照及公示系统一致
- 代理人：姓名须与授权委托书、身份证/律师证完全一致

#### 3.2 引言程序信息核阅

**比对逻辑**：
```
受理日期 ←→ 受理通知书日期
案件编号 ←→ 受理通知书/答辩通知书编号
组庭日期 ←→ 组庭通知日期
开庭日期 ←→ 开庭笔录首部日期
适用规则 ←→ 申请书/答辩书载明约定
```

#### 3.3 案情-仲裁请求核阅

**比对逻辑**：
```
1. 提取仲裁申请书中的原始请求
2. 提取变更请求申请书中的变更请求（如有）
3. 提取庭审笔录中最终确认的请求（以笔录为准）
4. 提取裁决书中的仲裁请求
5. 比对：
   - 如笔录与申请书不一致 → 以笔录为准，检查裁决书是否采用笔录版本
   - 如裁决书与笔录不一致 → 标记问题
```

**关键规则**：
> 以庭审笔录中最终确认的仲裁请求为准，而非申请书原始版本

#### 3.4 案情-证据核阅

**比对逻辑**：
```
1. 从证据清单/目录提取证据列表（编号、名称）
   → 证据清单通常在证据材料PDF的前几页

2. 从庭审笔录提取举证部分：
   - 申请人陈述提交的证据数量
   - 当庭提交的证据标注

3. 从裁决书提取列明的证据

4. 交叉比对：
   - 证据清单数量 vs 庭审笔录数量 vs 裁决书数量
   - 如不一致，检查是否有"当庭提交"或"庭后补充"
   - 核实补充证据是否在允许期限内提交
```

#### 3.5 案情-答辩意见核阅

**比对逻辑**：
```
1. 从答辩书提取主要答辩观点
2. 从庭审笔录提取庭审答辩意见
3. 从裁决书提取归纳的答辩意见
4. 比对：核心抗辩观点是否遗漏，表述是否准确
```

#### 3.6 仲裁庭意见核阅（请求权基础分析方法）

**核阅方法：请求权基础分析**

对每个仲裁请求，按照以下结构进行审查：

```
1. 识别请求权基础
   - 合同依据：具体条款
   - 法律依据：具体条文

2. 分析请求权构成要件
   - 要件一：[具体内容] → 事实认定 → 证据支持
   - 要件二：[具体内容] → 事实认定 → 证据支持
   - 要件三：[具体内容] → 事实认定 → 证据支持

3. 检查仲裁庭论证过程
   - 是否逐一回应每个要件
   - 事实认定是否有证据支持
   - 法律适用是否准确
```

**事实认定出处标注规则**：

仲裁庭意见中的每个事实认定，必须标注出处：
```
格式："事实陈述" [出处：材料名称 第X页/第X行 或 证据X第X页]

示例：
- "申请人于2025年1月15日将《催缴通知书》张贴于案涉房屋入户门上"
  [出处：庭审笔录第XX行；申请人证据5第X页]
- "被申请人欠付2024年12月16日至2025年1月20日的租金53852元"
  [出处：庭审笔录第XXX-XXX行；申请人证据2]
```

**检查要点**：
1. **争议焦点回应**：
   - 从庭审笔录提取仲裁庭归纳的争议焦点
   - 检查仲裁庭意见是否逐一回应

2. **当事人主张引用**：
   - 核对引用当事人主张的准确性
   - 核对引用证据的准确性
   - **必须标注出处**：申请人证据X第X页 / 被申请人证据X第X页 / 庭审笔录第X行

3. **事实认定**：
   - 每个事实认定是否有证据支持
   - **标注具体出处**：详见[材料名称]第X页
   - 事实认定是否与证据一致

4. **法律适用**：
   - 核对法律条款引用的准确性
   - 法律适用是否与事实认定匹配

5. **论证逻辑**：
   - 请求权要件是否完整
   - 要件与事实的对应关系是否清晰
   - 结论是否由前提逻辑推导得出

#### 3.7 裁决主文核阅

**检查要点**：
```
1. 漏裁检查：
   - 逐项核对最终确认的仲裁请求
   - 确认每项请求在主文中都有对应裁判

2. 超裁检查：
   - 确认主文裁判事项均在请求范围内

3. 金额核对：
   - 租金金额、滞纳金计算
   - 仲裁费金额与系统记录一致
   - 鉴定费金额（如有）与实际发生额一致

4. 计算核对：
   - 滞纳金起止日期
   - 利率标准
   - 计算公式
```

---

### 阶段四：格式核阅

按照 `rules/format-rules.md` 中的规则逐项检查：
- 字体、字号、行距
- 编号格式
- 日期、货币、数字格式
- 页码设置

**注意**：AI解析docx可能产生换行错误，须结合原文档确认

---

### 阶段五：法律合规核阅

按照 `rules/legal-rules.md` 中的规则检查：
- 法律依据准确性
- 事实认定与证据支持
- 主文与意见一致性
- 迟延履行后果表述

---

### 阶段六：逐句精细核阅

在以上步骤基础上，对裁决书全文进行逐句阅读，检查：
- 语句通顺性、逻辑连贯性
- 用词准确性、专业性
- 数字、日期、金额计算准确性
- 前后表述一致性
- 标点符号使用规范性

---

### 阶段七：输出结果

**输出位置规则**：
- 所有成果性文件必须输出到**案件所在文件夹**
- 禁止输出到临时文件夹

**输出文件清单**：

1. **带批注/修订的 Word 文件**
   - 文件名：`[案件编号]_裁决书初稿_核阅版.docx`
   - 位置：案件所在文件夹
   - 在问题位置添加批注
   - 批注格式见"输出格式规范"

2. **核阅报告（Markdown）**
   - 文件名：`核阅报告_[案件编号].md`
   - 位置：案件所在文件夹
   - 内容：
     - 案件材料清单
     - 信息要素映射表
     - 请求权基础分析
     - 比对结果与问题（含出处标注）
     - 修改建议（必须修改/建议修改）

3. **核阅报告（Word）**
   - 文件名：`核阅报告_[案件编号].docx`
   - 位置：案件所在文件夹
   - 便于打印和传阅的版本

## 核阅要点总纲

### 1. 首部当事人信息
- 当事人姓名/名称是否准确
- 自然人：身份证号码、住址是否与证件一致；外国人注明护照号码和国籍
- 法人/组织：法定代表人/负责人姓名、职务须与**裁决作出之日**国家企业信用信息公示系统公示信息一致（外资企业查其他官方网站）
- 委托代理人：姓名、单位、职务是否完整
  - **重要**：代理人姓名须与身份证明文件（身份证、律师证等）上的姓名完全一致
  - 如发现"张元 元"等多字情况，须核对原始证件
- 注意：无民事行为能力/限制行为能力人写明法定代理人

### 2. 引言程序描述
- 受理依据（合同名称、仲裁条款）是否完整
- 受理日期是否与受理通知一致
- 案件编号格式是否正确（立案号，非裁决号）
- 适用仲裁规则版本是否正确
- 程序类型（普通/简易）是否正确
- 组庭情况描述是否完整、准确
- 开庭情况（含缺席情形）是否完整

### 3. 案情部分
- **（1）仲裁请求**：裁决书中的仲裁请求描述与当事人实际主张是否一致，有无变更情况未体现
- **（2）证据**：证据列举是否有遗漏，质证意见是否完整
- **（3）代理意见**：答辩意见、庭审辩论意见归纳是否全面完整
- **（4）基本事实**：认定的基本事实是否有证据支持

### 4. 仲裁庭意见部分
- **（1）回应争议点**：是否充分回应了当事人的主要争议点
- **（2）依据充分**：论述是否有明确的法律依据、事实依据及合同依据
- **（3）不超预期**：支持或驳回请求的主要理由是否超出当事人预期或未经必要审理

### 5. 裁决主文部分
- **（1）费用金额**：仲裁费、鉴定费等金额是否准确，与系统显示费用是否一致
- **（2）漏裁/超裁**：是否存在漏裁（未裁请求项）或超裁（裁了未请求事项）
- **（3）主文与意见一致**：裁决主文与仲裁庭意见是否一致
- **（4）与最终请求无冲突**：主文表述与当事人确定的最终请求是否有冲突
- **（5）确定可执行**：主文内容是否满足确定、可执行的要求

## 内容比对规则（核心）

### 比对规则一：申请人仲裁请求
| 比对项 | 裁决书位置 | 比对来源 | 比对要点 |
|--------|-----------|----------|----------|
| 申请人申请称 | 案情第（一）部分 | 仲裁申请书【事实与理由部分】 | 主要事实描述是否一致，有无遗漏或失实 |
| 申请人最终确认的仲裁请求 | 案情第（一）部分末尾 | ①仲裁申请书【仲裁请求/请求事项】<br>②庭审笔录【申请人陈述仲裁请求部分】<br>③变更请求申请书（如有） | **以最后变更后的请求为准**；逐条比对，注意措辞差异和金额差异 |

> ⚠️ 关键规则：如果庭审笔录中申请人变更或确认了仲裁请求，以笔录中最终确认的版本为准，而非仲裁申请书原始版本。

### 比对规则二：被申请人答辩意见
| 比对项 | 裁决书位置 | 比对来源 | 比对要点 |
|--------|-----------|----------|----------|
| 被申请人答辩称 | 案情第（二）部分 | ①答辩书/答辩状【全文】<br>②庭审笔录【被申请人答辩意见部分】 | 主要答辩意见是否归纳全面，有无遗漏重要抗辩观点 |

### 比对规则三：反请求（如有）
| 比对项 | 裁决书位置 | 比对来源 | 比对要点 |
|--------|-----------|----------|----------|
| 被申请人反请求 | 案情第（三）部分 | ①仲裁反请求申请书<br>②庭审笔录【被申请人反请求陈述部分】 | 同申请人请求比对逻辑，以最终确认版本为准 |

### 比对规则四：证据列举
| 比对项 | 裁决书位置 | 比对来源 | 比对要点 |
|--------|-----------|----------|----------|
| 申请人证据 | 案情中"各方的证据情况"或相应部分 | ①申请人证据材料**前几页**（证据清单/证据目录）<br>②庭审笔录【申请人举证部分】，提取"证据X、证据X"等证据名称 | 证据编号和名称是否完整，有无遗漏；**缺少任意一份均需标注** |
| 被申请人证据 | 同上 | ①被申请人证据材料前几页（证据清单/证据目录）<br>②庭审笔录【被申请人举证部分】 | 同上 |

> ⚠️ 关键规则：证据编号须连续完整（如证据1至证据N），如裁决书跳号或总数不符，须标注。

### 比对规则五：仲裁请求覆盖性（漏裁/超裁检查）
| 检查项 | 裁决书位置 | 比对来源 | 比对要点 |
|--------|-----------|----------|----------|
| 所有请求项均有裁判 | 裁决主文 | 申请人/被申请人最终确认的仲裁请求（来自庭审笔录或变更申请书） | 逐条核对，主文中每项请求均应有明确裁判（支持/驳回/部分支持），不得遗漏 |
| 无超裁 | 裁决主文 | 同上 | 主文不得出现当事人未请求的事项 |
| 鉴定费裁判 | 裁决主文 | 鉴定报告（如有）、案件材料中鉴定费相关记录 | **有鉴定程序的案件，裁决主文必须对鉴定费作出裁判**，金额须与实际发生额一致 |
| 仲裁费裁判 | 裁决主文 | 系统显示仲裁费金额 | 仲裁费总额、申请人/被申请人分担比例、实际需支付金额须准确 |

## 格式核阅规则

### 国内裁决书格式规范

**字体字号**
| 位置 | 字体 | 字号 |
|------|------|------|
| 裁决书标题（如"XX仲裁委员会裁决书"） | 仿宋 | 二号 |
| 裁决书编号（如"（2024）XX仲裁0123号"） | 仿宋 | 小四号 |
| 当事人信息 | 仿宋 | 三号 |
| 内容大标题（"一 案情"、"二 仲裁庭意见"、"三 裁决"） | 仿宋 | 三号 |
| 裁决主体内容（正文） | 仿宋 | 三号 |
| （注意：涉及利息计算等表格的，为排版需要，可就表格中的文字缩小字号） | | |

**行间距与页边距**
| 项目 | 规范 |
|------|------|
| 大标题前后 | 各空一行 |
| 正文行间距 | 固定1.5倍 |
| 页边距 | 上2.54cm，下2.54cm，左3.18cm，右3.18cm |
| （注：排版难以调整时，可在该页最后一段注明"本页以下无正文"） | |

**页码设置**
- 首部页不设页码
- 首部页与正文页之间留空白页（为双面打印时封面背面留空白使用）
- 正文页开始连续编页码（从"1"开始）
- 最下方居中设置页码

**裁决书标题规范**
- 正式裁决书：`XX仲裁委员会裁决书`（按实际仲裁机构名称）
- 部分裁决书：`XX仲裁委员会部分裁决书`
- 中间裁决书：`XX仲裁委员会中间裁决书`

**裁决书编号规范**
- 正式裁决：`（20XX）XX仲裁字第XXXX号`（注意：一律用"仲裁"字，不是立案号）
- 部分裁决：`（20XX）XX仲部裁字第XXXX号`
- 中间裁决：`（20XX）XX仲中裁字第XXXX号`

**结构层次序号**
- 第一层：（一）（二）（三）
- 第二层：1. 2. 3.
- 第三层：（1）（2）（3）
- 各层级序号须排列准确、连贯

**数字、标点、日期规范**
- 使用阿拉伯数字（结构层次序数、引用文件或惯用语必须用汉字的除外）
- 三位数以上数字可不使用千分隔符，但全文须保持一致
- 日期须写明具体年月日，不得遗漏年份
- 货币须写明币种，两种以上币种须分别写明
- 引文（仲裁语言为中文的）外文引用须写明中文含义
- 标点符号须符合 GB/T 15834-2011《标点符号用法》

**国内裁决书结构规范**

**一、首部一般事项**
- 裁决书标题：`XX仲裁委员会裁决书` / `XX仲裁委员会部分裁决书` / `XX仲裁委员会中间裁决书`（按实际仲裁机构名称）
- 裁决书编号格式：
  - 正式裁决：`（20XX）京仲裁字第XXXX号`（注意：一律用"仲裁"字，第（空白，不是立案号）号）
  - 部分裁决：`（20XX）京仲部裁字第XXXX号`
  - 中间裁决：`（20XX）京仲中裁字第XXXX号`
- 当事人称谓：申请人、被申请人、被追加的当事人（注意不标序号）
- 当事人为自然人需载明：姓名、身份证号码（外国人注明护照号码和国籍）、住址（与身份证一致）、委托代理人姓名/单位/职务
- 当事人为法人/组织需载明：名称、住所、法定代表人/负责人姓名职务（须与裁决作出之日国家企业信用信息公示系统一致）、委托代理人姓名/单位/职务
- 无民事行为能力/限制行为能力人写明法定代理人：名称、同当事人关系
- 破产管理人：名称（以法院受理破产申请的裁定为准）
- 非诉讼行为能力人：法定代理人
- 裁决作出时已经撤销的当事人无需列明
- 裁决作出时已经撤销授权的委托代理人无需列明

**二、引言部分（常规程序说明）**
- 受理案件的依据：载有仲裁条款的合同名称
- 受理案件日期（须与受理通知一致）
- 案件编号：`（20XX）XX仲案字第XXXX号`（注意：此处是"案"字，是立案号）
- 适用仲裁规则及程序：规则版本、程序类型（普通/简易/国际商事）
- 仲裁材料提交与送达情况（可写明时间）
- 变更请求/反请求受理日期及送达情况
- 仲裁庭组成方式：仲裁员选定或指定、组庭时间
- 重新组庭（如有）：仲裁员退出情况、重新组庭的仲裁员组成、日期、程序是否重新进行
- 仲裁员回避（如有）：回避申请、主任决定情况
- 开庭审理情况：开庭日期、当事人出庭情况、庭审主要阶段（陈述答辩、举证质证、庭审调查、庭审辩论、最后陈述、调解）
- 延长审限情况（如有）
- **简称使用**：统一表述为"以下称……"，内容不加引号；当事人简称需要排列序号的，统一表述为"申请人一、申请人二……"；需要合称的，统一表述为"以下合称三申请人或申请人"
- **名称变更**：仲裁依据签订时与案件受理时的当事人名称之间发生变更、或仲裁程序进行中当事人名称发生过变更时，需要注明
- **程序顺序**：一般应依照程序开始时间的先后，特殊情况下可调整

**三、案情部分**
- 申请人仲裁请求（变更仲裁请求）及事实和理由：原意归纳或直接引用，准确列明请求事项（如有变更写明变更过程）
- 被申请人答辩意见及事实和理由
- 被申请人仲裁反请求（变更反请求）及事实和理由：准确列明反请求事项
- 申请人反请求答辩意见及事实和理由
- **证据表述**：证据统一表述为"申请人/被申请人提交证据（仲裁庭调取证据）如下：1. 2. 3."，序号前不再加"证据"，编号后为证据名称
- 仲裁庭收集的证据、鉴定结论及质证：出具人、时间、内容、各方质证意见
- （注意：上述三项务必要点全面、准确，忌冗长繁琐）
- **质证意见、认证意见**：案情部分不列明，关键证据的质证意见、认证意见在仲裁庭意见部分结合裁决对争议问题的论述进行分析论证
- **代理意见**：案情部分不列明，其中如有重要意见，可在仲裁庭意见部分结合裁决对争议问题的论述择要列明
- **币种**：出现货币单位时，需要注明币种，并视情况注明"以下同"
- **注释**：对证据内容、当事人的主张进行注释时，需要注明注释内容及"仲裁庭注"，并视情况注明"以下同"

**四、仲裁庭意见部分**
- 逐一分析和回应当事人的主张
- 论述与案情及其他部分前后呼应
- 引用的法律及法规确保准确无误
- 明确对各项请求的支持与驳回（包括部分支持、部分驳回）意见
- 涉及给付内容的，列明计算标准、方法和计算结果，确保明确具体
- 仲裁费及鉴定费、审计费、评估费（如有）的负担情况并说明理由
- （注意：表述要准确、简练、严谨，忌机械摘抄合同原文，忌长篇复制引用当事人代理意见）
- **合同效力**：若合同有效，参照"本案合同系各方当事人真实意思表示，不违反法律法规的强制性规定，应认定为有效"
- **认定事实**：主要列明有客观证据支持、各方无争议的事实；没有客观证据支持的，需要写明是当事人的表述；各方有争议的事实，可以列明各方具体争议内容，但本部分不建议对争议作出结论

**五、裁决主文部分**
- 普通程序写明裁决作出的仲裁员意见情况：合议意见/多数意见/首席意见
- 裁决事项严格依据当事人请求逐项列明：
  - 给付性质请求：给付义务人、给付对象、给付标的（注意货币单位/标的特定化）、给付方式
  - 利息等与时间相关的继续性请求：计算基数、计算标准、起止日期、暂计算至某特定日金额
  - （注意：不超裁、不漏裁，与仲裁庭意见一致）
- 未获得任何支持的仲裁请求写明：驳回申请人其他仲裁请求 / 驳回被申请人其他仲裁反请求
- 确定无管辖权的案件写明：驳回仲裁申请（注意不是"仲裁请求"）
- 仲裁费及鉴定费、审计费、评估费（如有）的处理：费用负担比例、支付方式
- 明确当事人履行义务的期限及逾期履行的后果：履行期限、逾期履行法律后果（金钱债务需注明"逾期支付的，加倍支付迟延履行期间的债务利息"）
- **裁决作出表述**："基于上述案情及意见，仲裁庭经合议，裁决如下"或"基于上述案情及意见，仲裁庭依多数意见，裁决如下"
- **裁决履行**：
  - 单方支付：写明支付内容、履行期限、逾期后果
  - 双方支付：写明抵销、支付内容、履行期限、逾期后果
  - 货币外给付：写明"逾期履行的，按照《中华人民共和国民事诉讼法》第二百五十三条的规定办理"（不写"加倍支付迟延履行期间的债务利息"）
  - 履行期限：一般统一为10天或者15天
- **签章落款**：本会公章、仲裁员签字、裁决日期、仲裁地

**六、尾部**
- "本裁决为终局（或部分、中间）裁决，自作出之日起生效。"

### 国际裁决书格式规范

**封面格式**（单倍行间距，页边距常规）
- 机构名称：按实际仲裁机构名称，仿宋小四粗体居中
- 案件编号：仿宋小四粗体居中，格式为`XX仲案字（年份）第XXXX号`**（与国内裁决一致，使用"仲案字"而非"仲裁字"）**
- 当事人名称：仿宋小四粗体居中；申请人/被申请人括号斜体另起一行；双方用"与"字隔开单独成行斜体
- 文书标题：仿宋小2号居中
- 适用规则版本：仿宋小四号居中，括号注明
- 仲裁庭成员：姓名后标注"首席"或"独任"，仿宋小四居中；"仲裁庭"粗体加下划线
- 仲裁地：仿宋小四居中；"仲裁地"粗体加下划线
- 作出日期：仿宋小四居中

> **注意**：AI解析docx文件时可能因文本提取方式产生换行错误（如日期、金额被拆分），核阅时须结合原文档Word文件确认实际格式，避免误判。

**正文格式**
- 字体：仿宋小四，1.5 倍行间距
- 段落：以阿拉伯数字连续编段号，悬挂缩进 1.27cm
- 标题层级：一、二、三 → （一）（二）→ 1. 2. 3. → （1）（2）（3）
- 引用完整法条/合同条款：加引号，斜体；如引用过长，单独成段，整体悬挂缩进 2.22cm
- 阿拉伯数字超过3位数：从个位数起每三位加英文逗号（如 1,000,000）
- 页码：每页标注，最下方居中

**尾部格式**
- 独任仲裁员：签名居中，本会公章在签名右下侧
- 三人仲裁庭：第一仲裁员和第二仲裁员同行，首席单独一行，呈倒三角状居中
- 如尾部与裁决主文无法同页，单独成页，前页注明"（本页以下无正文）"

> **重要说明**：国际裁决书除上述格式规范（字体、字号、排版等）有特殊规定外，其他**文字表述、法律合规、内容完整性**等规则均与国内裁决保持一致。具体包括：
> - 货币须写明币种
> - 日期须写明具体年月日
> - 外文引用须写明中文含义
> - 裁决主文须注明迟延履行后果
> - 法律条款引用须准确无误
> - 等等（详见国内裁决书格式规范）

## 输出格式规范

### Word 批注格式（每条批注必须包含以下字段）
```
【问题类型】格式 / 文字 / 内容比对 / 法律合规
【问题子类】标题格式 / 编号规范 / 仲裁请求比对 / 证据遗漏 / 漏裁 / 超裁 / 费用金额 / 其他
【优先级】必须修改 / 建议修改
【问题描述】（精准描述问题，引用原文）
【修改建议】（可直接使用的修改文案）
【规范依据】（引用具体规范条款或比对来源）
```

**优先级判定标准**
- **必须修改**：格式错误（字体/字号/编号）、内容遗漏（仲裁请求/证据/当事人信息）、漏裁/超裁、费用金额错误、法律条款引用明显错误
- **建议修改**：表述可优化、逻辑结构可调整、法律判断存疑（需人工确认）

## 规则迭代机制

**当 AI 漏检了某个问题时：**
1. 告诉 AI："你漏掉了一个问题：[描述问题]"
2. AI 会将此问题整理为新规则，追加到对应规则文件中
3. 在后续核阅中自动应用新规则

**当需要新增核阅规范时：**
1. 直接描述新规范："以后核阅时，[新规范描述]"
2. AI 整理后追加到规则库

**规则库版本记录**：每次修改规则时，在 `rules/changelog.md` 中记录修改内容和日期。
