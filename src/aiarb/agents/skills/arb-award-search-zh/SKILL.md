# 仲裁裁决检索

## 适用范围（先读）

本 skill 用于检索**中国大陆仲裁机构作出的仲裁裁决**。


## 数据源说明

### 主要数据源

| 数据源 | 覆盖范围 | 说明 |
|--------|---------|------|
| **中国裁判文书网** | 部分仲裁裁决（当事人申请撤销/不予执行时法院公示） | 有限覆盖 |
| **仲裁机构公开案例库** | 各仲裁委员会自愿公开 | 覆盖不完整 |
| **元典案例库（扩展）** | 含仲裁相关案例 | 需确认订阅 |
| **商业法律数据库** | 北大法宝/威科先行等仲裁栏目 | 需单独订阅 |

### 重要限制说明

⚠️ **与法院裁判文书不同，仲裁裁决不具有普遍公开性**：
- 仲裁以保密为原则（《仲裁法》第40条）
- 仅在以下情形裁决可能公开：
  1. 当事人同意公开
  2. 撤销/不予执行程序中法院裁定公开
  3. 仲裁机构年度报告/典型案例选编
  4. 学术研究匿名化处理后

## 检索策略

### 第一步：分析查询意图

从对话上下文获取用户查询需求：

**已知裁决案号**：
- 直接调用对应数据源查询
- 仲裁案号格式各异（不同于法院标准案号），需识别仲裁机构缩写

**主题案例检索**：
- 提炼关键词（案由、争议焦点、特殊事实）
- 确定筛选条件：
  - `arb_institution`：仲裁机构（CIETAC/SHIAC/BJIAC/SCIA/HKIAC/SIAC等）
  - `case_type`：案件类型（国内/国际/投资）
  - `dispute_type`：争议类型（合同/侵权/股权/知识产权等）
  - `date_range`：裁决日期范围
  - `outcome`：裁决结果（支持/驳回/部分支持）

### 第二步：分层检索

#### 工具选择矩阵

| 场景 | 首选方式 | 补充方式 |
|------|---------|---------|
| 已知裁决案号 | 直接查询数据源 | 仲裁机构官网核实 |
| 权威案例（仲裁机构发布） | 仲裁机构官网/年度报告 | 商业数据库 |
| 主题关键词检索 | 商业法律数据库 | 裁判文书网（撤销案件） |
| 事实相似判例 | 向量语义检索 | 人工筛选 |

### 第三步：输出结果

#### 检索结果列表格式

```
【仲裁裁决】（共 X 件）

1. {案件名称}
   案号：{仲裁案号}
   仲裁机构：{仲裁委员会名称}  |  裁决日期：YYYY-MM-DD  |  争议类型：{类型}
   案由：{案由}
   核心观点：{50-100字摘录}

...

如需某裁决全文，请告知案号。
```

#### 全文输出格式

```
【{案件名称}】
案号：{仲裁案号}
仲裁机构：{仲裁委员会}  |  裁决日期：{日期}  |  仲裁庭：{首席/独任/合议}
案由：{案由}

申请人：{名称} vs 被申请人：{名称}

{全文内容（分段呈现）}
```

## 仲裁裁决特殊分析维度

检索到仲裁裁决后，除常规案例分析外，还应关注以下**仲裁特有维度**：

### 1. 仲裁协议效力
- 仲裁条款的订立时间、形式
- 仲裁机构选择的明确性
- 仲裁事项范围的界定

### 2. 仲裁程序合规性
- 仲裁庭组成是否符合约定/规则
- 是否保障当事人程序权利（通知、陈述、举证）
- 是否超出仲裁协议范围（超裁）

### 3. 实体法律适用
- 合同准据法选择
- 国际仲裁中的冲突法问题
- 行业惯例/交易习惯的援引

### 4. 裁决可执行性
- 是否存在撤销风险
- 是否可能被不予执行
- 执行管辖法院确定

### 5. 一裁终局效力
- 裁决是否已生效（送达/公告期满）
- 是否已进入执行/撤销程序
- 既判力范围

## 与法院裁判文书检索的差异

| 维度 | 法院裁判文书 | 仲裁裁决 |
|------|-------------|---------|
| 公开性 | 原则公开 | 原则保密 |
| 案号格式 | 统一标准 | 各机构自定 |
| 检索平台 | 裁判文书网等 | 分散，无统一平台 |
| 覆盖率 | 近年案件基本全覆盖 | 极低（估计<5%） |
| 上诉/救济 | 二审/再审 | 撤销/不予执行（严格条件） |
| 执行力 | 判决具有执行力 | 裁决具有同等执行力 |

## 来源标签

- `[仲裁裁决]`：通过数据源实际返回的仲裁裁决内容
- `[法院文书-仲裁相关]`：撤销/不予执行/执行仲裁裁决的法院文书
- `[仲裁机构公开]`：仲裁机构官方发布的典型案例
- `[verify - 需用户自行核对]`：来源可靠性需用户确认的内容

## 工作约束

- **不编造裁决**：所有裁决信息必须来自实际检索结果
- **保密性提醒**：提示用户仲裁裁决的保密特性
- **时效说明**：仲裁实务发展较快，注意裁决时间的参考价值
- **救济途径提示**：检索同时关注相关的撤销/不予执行案件

## 本 skill 不做的事

- 不对法院诉讼案件使用（请用原版 `prc-legal-research-case-search`）
- 不保证能检索到特定仲裁裁决（受限于公开性）
- 不替代律师对具体事实的法律判断
- 不提供仲裁机构内部未公开的裁决
