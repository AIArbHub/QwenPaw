# 六段式审查框架SOP

## 框架来源

基于《上海法院类案办案要件指南》（全8册46类案件），经仲裁化适配后适用于仲裁审查场景。

## 六段式结构详解

### 第1部分：总体情况概述

**目的**：帮助仲裁员快速了解该类案件的全貌。

**内容**：
- 审理情况（案件数量、趋势）
- 案件特点（争议焦点、难点）
- 审查原则（法律适用原则）

**仲裁化适配**：
- 将"审判"改为"审查/裁决"
- 将"法院"改为"仲裁机构/仲裁庭"
- 删除"一审/二审"相关内容

---

### 第2部分：立案审查

**目的**：审查仲裁申请是否符合受理条件。

**核心审查要点**：

1. **主管审查**
   - 是否有有效的仲裁协议
   - 仲裁协议的范围是否覆盖争议事项
   - 是否属于仲裁机构受理范围

2. **管辖审查**
   - 仲裁机构的选择是否明确
   - 仲裁地的确定是否合法
   - 仲裁协议是否有效

3. **当事人主体审查**
   - 申请人/被申请人是否具备主体资格
   - 代理人是否有有效授权
   - 当事人是否适格

**仲裁化适配**：
- "主管审查"改为"仲裁协议效力审查"
- "管辖审查"改为"仲裁机构管辖审查"
- "当事人主体"保留但增加仲裁当事人特殊要求

---

### 第3部分：申请人请求的审查

**目的**：审查申请人的各项仲裁请求是否成立。

**审查方法**：
- 逐项审查每项仲裁请求
- 每项请求需有事实依据和法律依据
- 请求之间是否存在矛盾

**典型审查要点**：
- 请求确认之诉（合同效力、权利归属等）
- 请求给付之诉（返还财产、支付款项等）
- 请求变更之诉（合同解除、变更条款等）

**仲裁化适配**：
- "原告诉请"改为"申请人请求"
- "诉讼请求"改为"仲裁请求"
- 增加"仲裁请求与仲裁协议范围一致性"审查

---

### 第4部分：被申请人抗辩的审查

**目的**：审查被申请人的抗辩理由是否成立。

**抗辩分类**：

1. **事实层面抗辩**
   - 质量异议
   - 数量异议
   - 交付/履行异议

2. **法律层面抗辩**
   - 效力抗辩（合同无效/可撤销）
   - 时效抗辩（超过时效期间）
   - 条件抗辩（付款/验收条件未成就）

3. **证据层面抗辩**
   - 证据三性异议
   - 举证责任分配
   - 证据不足

4. **程序层面抗辩**
   - 管辖权异议
   - 仲裁协议效力异议
   - 程序违法

**仲裁化适配**：
- "被告抗辩"改为"被申请人抗辩"
- "管辖权异议"改为"仲裁管辖异议"
- 删除"反诉"概念，改为"反请求"

---

### 第5部分：要件事实审查和裁判规则

**目的**：对核心法律关系的要件事实进行审查，确定裁判规则。

**审查方法**：
- 识别核心法律关系
- 逐一审查各要件事实
- 适用证据规则

**核心内容**：
- 法律关系的认定（合同性质、效力等）
- 权利义务的分配
- 违约/侵权责任的认定
- 损害赔偿的计算
- 证据规则（举证责任、证据认定标准）

**仲裁化适配**：
- "裁判规则"改为"裁决规则"
- "判决"改为"裁决"
- 增加"仲裁裁决的效力"相关内容

---

### 第6部分：知识图谱

**目的**：以可视化方式总结案件核心要点。

**输出格式**：
1. Mermaid 思维导图（要件层级结构）
2. Mermaid 流程图（办案流程）
3. 交互式 JSON（程序化处理）

**图谱结构**：
```
案件类型
├── 立案审查
│   ├── 仲裁协议效力
│   ├── 仲裁机构管辖
│   └── 当事人主体资格
├── 申请人请求
│   ├── 请求1
│   └── 请求2
├── 被申请人抗辩
│   ├── 抗辩1
│   └── 抗辩2
└── 要件事实
    ├── 核心要件1 [核心]
    └── 核心要件2 [核心]
```

## 数据库支撑

以上所有框架内容均存储在 `case_frameworks.db` 数据库中，通过以下工具访问：

| 工具 | 数据库表 | 用途 |
|------|---------|------|
| `identify_case_type` | case_types | 案件类型识别 |
| `generate_review_checklist` | case_frameworks, review_points | 框架+要点 |
| `dual_perspective_analysis` | review_points, evidence_checklists, reinforcement_templates | 双视角分析 |
| `legal_qa_consultation` | 全表 | 智能问答 |
