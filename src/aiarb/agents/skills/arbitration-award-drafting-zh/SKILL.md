# 仲裁裁决书撰写技能

本技能用于根据案件材料撰写仲裁裁决书，涵盖国内/国际仲裁裁决书的标准化撰写规范。

## 适用场景

- 撰写国内仲裁裁决书（普通程序/简易程序）
- 撰写国际仲裁裁决书（普通程序/简易程序）
- 裁决书格式自查

## 使用场景触发词

- "帮我撰写裁决书"
- "起草裁决/裁决书"
- "生成裁决书草稿"
- 用户提供案件材料 + 要求撰写裁决时

## 输入要求

### 必须提供
1. **案件材料**：仲裁申请书、答辩意见、证据清单、庭审笔录等
2. **裁决书类型**：国内案件 / 国际案件
3. **程序类型**：简易程序 / 普通程序

### 建议同时提供
- 仲裁规则版本及适用程序
- 当事人工商信息/身份信息
- 委托代理手续
- 组庭通知
- 鉴定报告（如有）
- 变更仲裁请求申请书（如有）

## 撰写流程

### 第一步：确定裁决类型

根据案件信息确定：
1. **国内 vs 国际**：当事人是否涉及涉外因素（外国法人、自然人、跨境合同等）
2. **普通程序 vs 简易程序**：根据仲裁规则确定适用程序
3. **裁决类型**：终局裁决/部分裁决/中间裁决

### 第二步：收集必要信息

撰写前需获取以下材料：
- 仲裁申请书（含请求事项）
- 答辩意见
- 反请求申请书（如有）
- 证据清单及质证意见
- 庭审笔录
- 组庭通知
- 仲裁规则版本及适用程序
- 当事人工商信息/身份信息
- 委托代理手续

### 第三步：按五大结构撰写

#### 一、首部

**原则：一字不差。**

依据：国家企业信用信息公示系统、全国组织机构统一社会信用代码公示查询平台等。

必备内容：
- 文书编号：格式为（年份）京仲裁字第XXX号
- 当事人称谓：申请人、被申请人、被追加的当事人
- 自然人：姓名、身份证号码、住址
- 法人/非法人组织：名称、住所、法定代表人及其职务
- 委托代理人：姓名、单位及职务（先内部后外部排序）
- 特殊情况：法定代理人（无诉讼行为能力人）、破产管理人

注意事项：
- 裁决作出时已撤销的当事人/已撤销授权的代理人无需列明
- 法定代表人职务不明可空缺
- 分公司用"经营场所"和"负责人"
- 律所用"住所"，负责人用"负责人"
- 个体工商户用"经营场所"
- 合伙用"主要经营场所"和"执行事务合伙人"

#### 二、引言

**原则：程序全面、语言精炼。**

依据：仲裁通知。

一般程序内容（按时间顺序）：
1. **基础信息**：本会名称、当事人名称、仲裁依据、受理时间、案号
2. **规则依据**：规则名称、施行时间、适用程序
3. **材料送达**：送达内容
4. **组庭情况**：仲裁庭组成人员及产生方式、组庭日期、开庭日期、送达情况、异议情况
5. **开庭情况**：开庭日期、地点、出庭人员、开庭程序（陈述、答辩、举证、质证、调查、辩论、最后陈述）
6. **延审情况**（如有）：申请主体、批准主体
7. **裁决作出**：审结情况、合议结果

特殊程序内容（如有，按时间顺序）：
- 反请求
- 变更请求/反请求
- 管辖权异议
- 追加当事人
- 仲裁员回避
- 重新组庭
- 中止及恢复程序
- 鉴定
- 仲裁庭调查取证
- 程序变更
- 审理措施（问题单、审理范围书等）

简称规则：统一表述为"以下称……"，内容不加引号。多当事人需序号排列，统一表述为"申请人一、申请人二……"。需要合称的，统一表述为"以下合称三申请人或申请人"。

名称变更：仲裁依据签订时与案件受理时的当事人名称之间发生变更、或仲裁程序进行中当事人名称发生过变更时，需要注明。

#### 三、案情

**原则：保留原意，概括大意。**

内容：
1. **申请人仲裁请求**：以仲裁申请书为主，庭审笔录为补充。有变更的写明变更过程，最终固定请求统一表述为"申请人最终确认的仲裁请求如下："
2. **被申请人答辩意见**：以书面答辩意见为主，庭审笔录为补充
3. **被申请人仲裁反请求**（如有）：同仲裁请求
4. **申请人反请求答辩意见**（如有）：同答辩意见
5. **证据**：统一表述为"申请人/被申请人提交证据（仲裁庭调取证据）如下：1. 2. 3."，序号前不再加"证据"，编号后为证据名称

注意事项：
- 质证意见、认证意见不在案情部分列明，在仲裁庭意见部分结合争议问题论述
- 代理意见不在案情部分列明，重要意见在仲裁庭意见部分择要列明
- 证据过多时可简列，以"等"代替
- 货币需注明币种，视情况注明"以下同"
- 注释需注明"仲裁庭注"，并视情况注明"以下同"

#### 四、仲裁庭意见

**原则：依据准确、回应充分、理由妥当。**

**请求权基础分析方法：**

对每个仲裁请求，按照以下结构进行论证：

```
1. 识别请求权基础
   - 合同依据：具体条款
   - 法律依据：具体条文

2. 分析请求权构成要件
   - 要件一：[具体内容] → 事实认定 → 证据支持
   - 要件二：[具体内容] → 事实认定 → 证据支持
   - 要件三：[具体内容] → 事实认定 → 证据支持

3. 论证过程
   - 逐一回应每个要件
   - 事实认定须有证据支持
   - 法律适用须准确
   - 结论由前提逻辑推导得出
```

**事实认定出处标注规则：**

仲裁庭意见中的每个事实认定，必须标注出处：
```
格式："事实陈述" [出处：材料名称 第X页/第X行 或 证据X第X页]

示例：
- "申请人于2025年1月15日将《催缴通知书》张贴于案涉房屋入户门上"
  [出处：庭审笔录第XX行；申请人证据5第X页]
```

内容：
1. **合同效力**：若有效，参照统一表述"本案合同系各方当事人真实意思表示，不违反法律法规的强制性规定，应认定为有效"；若无效，根据案情决定；不宜明确效力的可省略
2. **特殊程序**：裁决前未作结论的程序需详细论述理由
3. **认定事实**：列明有客观证据支持、各方无争议的事实；没有客观证据支持的，需要写明是当事人的表述；各方有争议的事实，可以列明各方具体争议内容，但本部分不建议对争议作出结论
4. **裁决依据**：事实依据须在证据中找到出处；合同依据须在合同文本中找到出处；法律依据须确认有效且表述无误
5. **费用承担**：写明分配比例，具体数额在裁决主文写明
6. **其他**：撰写顺序和论述方式由仲裁庭自主决定

要求：
- 逐一分析和回应当事人主张
- 论述与案情及其他部分前后呼应
- 引用法律准确无误
- 明确对各项请求的支持与驳回（包括部分支持、部分驳回）意见
- 涉及给付内容的，列明计算标准、方法和计算结果，确保明确具体
- 仲裁费及鉴定费、审计费、评估费（如有）的负担情况并说明理由
- 忌机械摘抄合同原文，忌长篇复制引用当事人代理意见

#### 五、裁决主文

**原则：不超不漏、前后一致、表述妥当。**

依据：最终固定的请求/反请求、仲裁庭意见的结论。

内容：
1. **裁决作出**：普通程序写明合议结果："基于上述案情及意见，仲裁庭经合议，裁决如下"或"基于上述案情及意见，仲裁庭依多数意见，裁决如下"
2. **主文内容**：
   - 给付性请求：给付义务人、给付对象、给付标的（注意货币单位/标的特定化）、给付方式
   - 利息等继续性请求：计算基数、计算标准、起止日期、暂计算至某特定日金额
   - 确认性请求：确认对象、确认结果
   - 形成性请求：变动对象、变动结果
   - 担保性请求：担保权人、担保物、担保债务、担保效果/保证方式
   - 驳回请求：驳回申请人其他仲裁请求 / 驳回被申请人其他仲裁反请求
   - 确定无管辖权的案件：驳回仲裁申请（注意不是"仲裁请求"）
   - 费用承担：总额（分项）、分担金额、支付内容
3. **裁决履行**：支付内容、履行期限（一般10天或15天）、逾期后果
   - 金钱债务：加倍支付迟延履行期间的债务利息
   - 非金钱债务：按照《中华人民共和国民事诉讼法》规定办理
4. **裁决生效**：本裁决为终局（或部分、中间）裁决，自作出之日起生效
5. **签章落款**：本会公章、仲裁员签字、裁决日期、仲裁地

#### 国际裁决特殊要求

国际案件裁决书结构略有不同，分为六部分：
1. **简介**：当事人、仲裁庭、本案合同、仲裁条款、适用规则、适用法、仲裁地、仲裁语言
2. **仲裁程序概述**：按时间顺序记录主要程序
3. **案件事实概述及有关合同约定**：简要介绍背景及合同约定
4. **当事人的仲裁请求及主张**：请求、答辩、反请求、证据、鉴定程序
5. **仲裁庭意见**：合同效力、争议焦点分析、请求认定、费用分担
6. **裁决主文**

国际裁决格式要求：
- 封面单独成页
- 正文字体仿宋小四，1.5倍行间距
- 段间以阿拉伯数字连续编段号，悬挂缩进1.27厘米
- 引用完整法条/合同条款加引号并斜体
- 三位数以上阿拉伯数字每三位加英文逗号
- 目录不超过三级
- 封面案件编号使用"京仲案字"（与国内一致）
- 独任仲裁员签名居中，本会公章在签名右下侧
- 三人仲裁庭：第一仲裁员和第二仲裁员同行，首席单独一行，呈倒三角状居中
- 如尾部与裁决主文无法同页，单独成页，前页注明"（本页以下无正文）"

### 第四步：格式自查

完成撰写后，对照以下格式规范自查：

**字体字号**：
- 裁决书标题：仿宋二号
- 裁决书编号：仿宋小四号
- 当事人信息：仿宋三号
- 内容大标题（一 案情、二 仲裁庭意见、三 裁决）：仿宋三号
- 裁决主体内容：仿宋三号

**排版**：
- 大标题前后各空一行
- 正文行间距固定为1.5倍
- 页边距：上2.54cm，下2.54cm，左3.18cm，右3.18cm
- 首部页不设页码
- 首部页与正文页之间留空白页
- 正文页从"1"开始连续编页码，最下方居中

**标点数字**：
- 标点符合GB/T 15834-2011
- 货币写明币种，视情况注明"以下同"
- 日期写明具体年月日
- 阿拉伯数字（结构层次序数等惯用语除外）
- 三位数以上数字千分隔全文保持一致
- 外文引用写明中文含义

**结构层次**：
- 第一层：（一）
- 第二层：1.
- 第三层：（1）
- 各层次项下序号排列准确、连贯

## 撰写自查清单

完成撰写后，须逐项核对以下自查清单：

### 首部自查
- [ ] 裁决书标题格式正确（"仲裁裁决书/部分裁决书/中间裁决书"）
- [ ] 裁决书编号格式正确：（年份）京仲裁字第XXX号（一律用"仲裁"字）
- [ ] 当事人称谓正确（申请人、被申请人、被追加的当事人，不标序号）
- [ ] 自然人信息完整：姓名、身份证号码（外国人注明护照号码和国籍）、住址
- [ ] 法人/组织信息完整：名称、住所、法定代表人/负责人姓名职务
- [ ] 法定代表人须与裁决作出之日国家企业信用信息公示系统一致
- [ ] 委托代理人信息完整：姓名、单位及职务（先内部后外部排序）
- [ ] 已撤销的当事人/代理人已移除
- [ ] 无诉讼行为能力人已列明法定代理人及关系
- [ ] 破产管理人已列明（如有）

### 引言自查
- [ ] 受理案件依据（载有仲裁条款的合同名称）完整
- [ ] 受理日期与受理通知一致
- [ ] 案件编号格式正确：（年份）京仲案字第XXX号（此处是"案"字，是立案号）
- [ ] 适用仲裁规则版本及程序类型正确
- [ ] 材料送达情况已写明
- [ ] 组庭情况完整：仲裁员选定/指定方式、组庭日期
- [ ] 开庭情况完整：开庭日期、出庭人员、庭审程序
- [ ] 缺席情况已正确表述（如有）
- [ ] 延审情况已写明（如有）
- [ ] 特殊程序已按时间顺序列明（如有）
- [ ] 简称使用规范："以下称……"，不加引号
- [ ] 当事人名称变更已注明（如有）

### 案情自查
- [ ] 申请人仲裁请求与最终确认版本一致
- [ ] 变更过程已写明（如有）
- [ ] 被申请人答辩意见归纳全面
- [ ] 被申请人反请求准确列明（如有）
- [ ] 申请人反请求答辩意见准确列明（如有）
- [ ] 证据表述格式正确："申请人/被申请人提交证据如下：1. 2. 3."
- [ ] 证据编号连续完整，无遗漏
- [ ] 质证意见、认证意见不在案情部分列明
- [ ] 代理意见不在案情部分列明
- [ ] 币种已注明
- [ ] 注释格式正确（"仲裁庭注"）

### 仲裁庭意见自查
- [ ] 逐一分析和回应当事人主张
- [ ] 充分回应主要争议点
- [ ] 合同效力已论述（参照统一表述）
- [ ] 认定事实有证据支持
- [ ] 事实认定标注出处
- [ ] 法律条款引用准确无误（名称、条款号、内容）
- [ ] 明确对各项请求的支持与驳回意见
- [ ] 涉及给付内容的列明计算标准、方法和结果
- [ ] 费用负担有理由说明
- [ ] 论述与案情前后呼应
- [ ] 忌机械摘抄合同原文
- [ ] 忌长篇复制代理意见

### 裁决主文自查
- [ ] 裁决作出表述正确（"基于上述案情及意见，仲裁庭经合议/依多数意见，裁决如下"）
- [ ] 不超裁：主文裁判事项均在请求范围内
- [ ] 不漏裁：每项请求都有对应裁判
- [ ] 裁决主文与仲裁庭意见一致
- [ ] 裁决主文与最终请求无冲突
- [ ] 给付性请求：给付义务人、给付对象、款项性质和数额明确
- [ ] 利息等继续性请求：计算基数、标准、起止日期、暂计金额齐全
- [ ] 费用承担：总额（分项）、分担金额、支付方式明确
- [ ] 费用金额与系统显示一致
- [ ] 鉴定费已裁判（如有鉴定程序）
- [ ] 履行期限明确（一般10天或15天）
- [ ] 逾期后果正确（金钱债务：加倍支付迟延履行期间的债务利息；非金钱债务：按照民诉法规定办理）
- [ ] 驳回请求表述正确
- [ ] 裁决生效表述正确
- [ ] 签章落款完整：本会公章、仲裁员签字、裁决日期、仲裁地

### 格式自查
- [ ] 字体字号符合规范
- [ ] 行间距1.5倍
- [ ] 页边距正确
- [ ] 页码设置正确
- [ ] 标点符合GB/T 15834-2011
- [ ] 结构层次序号正确
- [ ] 序号排列准确、连贯

## 输出格式规范

### 裁决书文件
- 文件名：`[案件编号]_裁决书.docx`
- 位置：案件所在文件夹
- 须为 Word 格式（.docx）

### 撰写说明文件
- 文件名：`裁决撰写说明_[案件编号].md`
- 位置：案件所在文件夹
- 内容：
  - 案件基本信息
  - 撰写要点说明
  - 请求权基础分析
  - 需人工确认事项

## 注意事项

1. 裁决书编号格式为（年份）仲裁字第XXX号（不是立案号）
2. 案件编号格式为（年份）案字第XXX号（是立案号）
3. 仲裁员是否加先生/女士保持前后统一
4. 多次开庭的可一同表述（如程序无重大差异）
5. 被申请人全部缺席时，庭审程序表述需调整
