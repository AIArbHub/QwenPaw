# 数据来源与版权边界

本文档是知识库入库的**合规基线**。判定原则：**收录事实与官方文本，回避他人编排成果与整篇复制。**

## 1. 版权边界判定

| 数据类型 | 版权状态 | 处置方式 |
|---|---|---|
| 法律、行政法规、司法解释 | **不受著作权保护**（官方正式文本） | 可直接内置全文，注明发布机关与版本日期 |
| 国际公约（如纽约公约） | 官方文本无版权 | 可直接内置；译本注明译者来源 |
| 仲裁机构规则 | 机构公开发布文本，**视为可引用** | 内置全文，注明机构 + 版本 + 施行日 + 来源 URL |
| 公开案例（裁判文书） | 文书本身公开，但**数据库编排受保护** | 只入**结构化整理**（案由/焦点/要旨），**不整篇复制原文** |
| 公众号/媒体分析文章 | 作者享有著作权 | **不入库**；仅可作为线索，据此去核对官方来源 |
| 实务书籍、办案笔记 | 受版权保护 | **不入库**；仅用户自有材料可本地私有使用 |
| 用户自有案件材料 | 用户自有，敏感性最高 | 本地私有工作区，**不进共享库**，不出域 |

**一句话规则**：官方文本可全文收录；他人成果只取事实、不取表达；用户材料只留本地。

## 2. 公开数据源清单

用于采集与核对，采集后仍须回归官方源验证。

| 用途 | 渠道 | 说明 |
|---|---|---|
| 仲裁规则 | 各机构官网（贸仲、某仲裁机构、上海国仲、深国仲、港仲等） | **首选官方源**，直接下载现行版本 |
| 法律法规 | 国家法律法规数据库、人大网、最高法官网 | 官方正式文本 |
| 案例与研究 | 临时仲裁、采安仲裁等公开公众号与行业媒体 | 仅作**线索源**，要点须回溯官方/公开文书核对 |
| 裁判文书 | 中国裁判文书网等公开渠道 | 入库前必须脱敏 |
| 国际仲裁 | ICC、LCIA、SIAC、HKIAC 官网及公开数据库 | 英文原文优先 |

> 采集纪律：从公众号/媒体获得的观点，**必须**回到官方文本或公开文书验证后才能入库；无法验证的一律标 `confidence: draft` 并提示复核。

## 4. 用户上传材料处理约定

1. 用户上传的裁决书、合同、证据等**只进私有工作区**，不写入 `knowledge_base/` 共享库。
2. 需要引用时，由 Agent 在工作区内检索，结果不外发、不上云。
3. 若用户主动要求将自有材料沉淀为经验（如脱敏后的裁判要旨），需**先脱敏**再入共享库，并标 `source_type: user-upload`、`redacted: true`。

## 5. 存疑处理

对任何来源存疑的内容：**不入库**，记为待办并提示用户人工判断。宁可缺，不可错。
