# 仲裁规则库（rules）

存放各仲裁机构现行规则、费用表与专项程序规则。**机构公开发布文本，可内置全文，须注明机构、版本、施行日与来源 URL。**

采集前必读：`../SCHEMA.md`、`../SOURCES.md`。

> **采集范围**：司法部 2025 年 8 月遴选的 **22 家"中国特色国际一流仲裁机构培育工程"首批培育对象**为重点。
> 一家机构可能有多套规则（国内仲裁、涉外/国际仲裁、金融、建设工程、互联网仲裁、简易程序、调解规则等），
> **按"机构—规则—版本"分文件存放**，不要合并。

## 采集要求

1. **只采现行版本**，旧版本如需保留用于历史案件，文件名缀年份并标 `effective_date`。
2. 规则修订频繁，每年至少核对一次版本有效性。
3. 费用表单独成文，便于按标的额检索。
4. 中文机构规则采中文原文；国际机构规则保留英文原文，不做翻译改写（需译本时另立文件并注明译者来源）。
5. 采集后在 `../SOURCES.md` 台账登记。

> 注意：**不得**凭记忆填写规则条款、期限或费用标准。检索不到即如实说明。
