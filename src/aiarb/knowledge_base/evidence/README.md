# 证据清单模板库

本目录存储各案件类型的证据清单模板，作为 `evidence_checklists` 表的 Markdown 参考。

## 目录结构

```
evidence/
├── by_case_type/        # 按案由分类
│   ├── 民间借贷.md
│   ├── 买卖合同.md
│   ├── 建设工程.md
│   └── ...
├── general/             # 通用证据清单
│   ├── 申请人通用.md
│   ├── 被申请人通用.md
│   └── ...
└── README.md           # 本文件
```

## 文件格式

```markdown
# [案件类型]证据清单

## 申请人证据
| 序号 | 证据名称 | 类型 | 必要性 | 说明 |
|------|---------|------|--------|------|
| 1 | 借条/借款合同 | 书证 | 必需 | 证明借贷关系 |
| 2 | 转账凭证 | 电子数据 | 必需 | 证明款项交付 |

## 被申请人证据
| 序号 | 证据名称 | 类型 | 必要性 | 说明 |
|------|---------|------|--------|------|
| 1 | 还款凭证 | 书证 | 必需 | 证明已还款 |
```

## 必要性等级

| 等级 | 说明 |
|------|------|
| 必需 | 核心证据，缺失则承担举证不利后果 |
| 重要 | 关键证据，缺失影响胜诉概率 |
| 辅助 | 补充证据，增强主张可信度 |

## 数据来源

- 主要来源：仲裁实务经验
- 法律声明：所有清单仅供参考，不构成法律意见
