# 双向视角模板库

本目录存储申请人/被申请人双向视角分析模板，作为 `dual_perspective_analysis` 工具的结构化参考。

## 目录结构

```
bidirectional/
├── applicant/           # 申请人视角模板
│   ├── 通用模板.md
│   ├── 合同纠纷.md
│   ├── 侵权纠纷.md
│   └── ...
├── respondent/          # 被申请人视角模板
│   ├── 通用模板.md
│   ├── 合同纠纷.md
│   ├── 侵权纠纷.md
│   └── ...
└── README.md           # 本文件
```

## 申请人视角模板格式

```markdown
# [案件类型] — 申请人视角分析模板

## 优势点识别
1. [优势点1]
2. [优势点2]

## 劣势点/缺失要素
1. [劣势点1]
2. [劣势点2]

## 证据清单
| 序号 | 证据名称 | 必要性 | 说明 |

## 胜诉概率评估
**[高/中/低]** — [评估依据]
```

## 被申请人视角模板格式

```markdown
# [案件类型] — 被申请人视角分析模板

## 申请人主张薄弱点
1. [薄弱点1]
2. [薄弱点2]

## 抗辩策略
| 层面 | 抗辩要点 | 事实依据 | 法律依据 |

## 反证清单
| 序号 | 证据名称 | 对应抗辩 | 必要性 |

## 预期抗辩效果
> [效果评估]
```

## 数据来源

- 主要来源：仲裁实务经验总结
- 法律声明：所有模板仅供参考，不构成法律意见
