# 案例库（cases）

存放典型仲裁案例的**结构化整理**（案由、争议焦点、裁判要旨）。

**版权纪律**：公开案例只入结构化整理，**不整篇复制原文**；所有案例入库前必须脱敏。详见 `../SOURCES.md`。

采集前必读：`../SCHEMA.md`、`../SOURCES.md`。

## 单案文档结构

```markdown
---
title: <主题>
category: cases
case_no: <案号，无则填 无>
institution: <作出机构>
decision_date: YYYY-MM-DD
cause: <案由>
issues: [争议焦点1, 争议焦点2]
holding: <一句话裁判要旨>
source: <来源 URL>
source_type: public-web | user-upload
redacted: true
confidence: verified | draft
---

## 基本事实
（脱敏后的事实摘要）

## 争议焦点
1. …
2. …

## 裁判要旨
…

## 说理要点
（仲裁庭的论证路径，不抄原文，用自己的话结构化归纳）

## 实务提示
（对办案的可迁移经验）
```

## 来源渠道

| 渠道 | 用法 | 注意 |
|---|---|---|
| 临时仲裁、采安仲裁等公开公众号/媒体 | **线索源** | 只能据此发现案例，要点须回溯官方或公开文书核对 |
| 中国裁判文书网等公开数据库 | 原文核对 | 入库前脱敏 |
| 机构公开裁决书/年度案例选 | 官方源 | 优先 |
| 用户自有办案材料 | 主要来源 | 脱敏后才可入共享库，否则留在私有工作区 |

## 脱敏要求

入库前必须移除或替换：

- 当事人姓名/名称 → `申请人` / `被申请人` / `A 公司` / `B 公司`
- 身份证号、统一社会信用代码、银行账号、联系方式
- 具体金额（可保留数量级或比例关系，保留计算逻辑）
- 仲裁员姓名、案号（除非本身就是公开案例）

`redacted: false` 的文件**禁止**放入共享库。

## 建议的主题分类目录

`cases/` 下可按主题分子目录，便于检索：

- `仲裁协议效力/`
- `管辖与管辖权异议/`
- `程序事项/`（组庭、回避、证据、鉴定）
- `合同实体争议/`（违约、解除、违约金调整）
- `建设工程/`
- `金融与投资/`
- `涉外与执行/`（承认与执行、撤销裁决）
- `核阅要点/`（从裁决书核阅实践中反推的常见错误与规范）

## 采集纪律

1. **不得编造**案号、裁决日期、裁判要旨。
2. 从公众号/媒体获得的观点，回溯核对后方可标 `verified`；未核对标 `draft` 并在引用时提示复核。
3. 每份入库在 `../SOURCES.md` 台账登记。

> 首批内容建议来源：从已有裁决书核阅成果（如 (2025) 京仲案字第 01230 号、01253 号、20220350 号）脱敏后反推裁判要旨与核阅要点，这是别人拿不走的资产。
