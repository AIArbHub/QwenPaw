# 一般人格权纠纷（不适用仲裁）

## 不适用仲裁说明

此案由属于一般人格权纠纷，根据《中华人民共和国仲裁法》第三条，下列纠纷不能仲裁：
1. 婚姻、收养、监护、扶养、继承纠纷；
2. 依法应当由行政机关处理的行政争议。

此外，侵权纠纷、人格权纠纷、公益诉讼、执行程序、破产程序等也不属于仲裁范围。

本案由仅作为案由体系完整性参考，不提供仲裁裁判规则。
