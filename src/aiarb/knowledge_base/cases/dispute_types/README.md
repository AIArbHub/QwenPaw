# 仲裁争议类型规则库

本目录按**法院民事案由**切分，完整复刻自 LegalWork 8203 案由裁判规则库（257 个案由），并对涉及仲裁的案由做了**仲裁化适配改造**。

## 数据来源

- **原始来源**：LegalWork 8203 案由规则库（`D:\Project\legalwork-main\skills\8203\类案纠纷案例库加强版\08-案例库裁判规则部`）
- **案由数量**：257 个（覆盖最高人民法院《民事案件案由规定》全部一级至四级案由）
- **原始规则来源**：人民法院案例库入库案例提炼的裁判规则
- **迁移工具**：`scripts/migrate_8203_causes.py`

## 仲裁化适配改造

对涉及仲裁的案由，执行以下术语替换：

| 原文（法院视角） | 替换后（仲裁视角） |
|---|---|
| 法院 | 仲裁庭/仲裁机构 |
| 法官 | 仲裁员 |
| 原告 | 申请人 |
| 被告 | 被申请人 |
| 起诉 | 申请仲裁 |
| 立案 | 受理 |
| 开庭 | 开庭审理 |
| 判决 | 裁决 |
| 裁定 | 决定 |
| 审判长 | 首席仲裁员 |
| 合议庭 | 仲裁庭 |
| 书记员 | 办事秘书 |
| 诉讼时效 | 仲裁时效 |
| 诉讼标的 | 争议标的 |
| 诉讼请求 | 仲裁请求 |
| 反诉 | 反请求 |
| 撤诉 | 撤回仲裁申请 |

**保留不变的术语**：人民法院案例库、入库编号（案例来源标识，不变替换）。

## 文件结构

每个案由文件遵循统一格式：

```yaml
---
title: 案由名称
category: cases

dispute_type: DT-NNN
arbitration_category: core | procedure | intl | pure_litigation
applicable_law: [适用法律]
applicable_rules: [适用仲裁规则]
source: LegalWork 8203 案由规则库复刻（仲裁化适配）
source_type: migrated
redacted: true
confidence: draft
---
```

## 合规说明

1. **8203 规则文本有独创性**，但提炼自人民法院案例库入库案例（公共司法知识）。本库复刻了其组织方式和裁判规则内容，做了仲裁化适配改造。
2. **裁判规则本身属公共司法知识**，入库案例编号为公开信息。
3. **仲裁化适配后的文本**与原文存在术语差异，使用前请对照原文确认适配准确性。
4. **程序性规则**以《仲裁法》（2026-03-01 施行）和机构规则为准，8203 的程序性规则仅作参考。

## 采集纪律

1. **规则来源于公开案例或实务经验**，不编造法条和案号
2. **每个规则标注来源**：入库编号或"实务经验"
3. **面向非专业人士输出**：不扮演仲裁员，不写代理意见
4. **持续补充**：从实际办案中反向提炼规则，这是不可被复制的资产
5. **入库前脱敏**：真实案卷信息脱敏后才可入库
6. **法条时效核验**：引用法条前须核验现行有效版本（特别注意 2026-03-01 新仲裁法施行）
