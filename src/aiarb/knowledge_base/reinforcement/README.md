# 补强建议库

本目录存储案件要件缺失要素的补强建议模板，作为 `reinforcement_templates` 表的 Markdown 参考。

## 目录结构

```
reinforcement/
├── templates/           # 补强建议模板
│   ├── 通用补强.md
│   ├── 合同纠纷补强.md
│   ├── 侵权纠纷补强.md
│   └── ...
└── README.md           # 本文件
```

## 模板格式

```markdown
# [案件类型]补强建议

## 缺失类型：[类型名称]

### 补强建议1
- **建议内容**：...
- **优先级**：1（最高）/ 2 / 3 / 4 / 5（最低）
- **难度**：简单/中等/困难
- **预计时间**：...

### 补强建议2
...
```

## 优先级说明

| 优先级 | 说明 | 典型场景 |
|--------|------|---------|
| 1（最高） | 必需证据缺失 | 核心书证不存在 |
| 2 | 重要证据缺失 | 履行凭证不足 |
| 3 | 证据质量需提升 | 证据关联性较弱 |
| 4 | 补充证据 | 增强可信度 |
| 5（最低） | 辅助材料 | 佐证类材料 |

## 数据来源

- 主要来源：仲裁实务经验
- 法律声明：所有建议仅供参考，不构成法律意见
