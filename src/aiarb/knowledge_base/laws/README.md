## 采集要求

1. **必须采现行有效版本**，并在文档头写清 `version` 与 `effective_date`。
2. 条文**逐字录入**，保留条、款、项编号。
3. 修订频繁的单独标注 `confidence: draft`。
4. 采集后在 `../SOURCES.md` 台账登记一行。
5. **不得凭记忆填写条文内容**。宁可空着，不可错填。
6. 同步后运行 `python scripts/sync_kb_scaffold.py` 将新文件推到 `~/.aiarb/knowledge_base/`。
