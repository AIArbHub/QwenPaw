## 格式与排版要求（统一规范）

所有模板与生成文书必须满足以下一致性要求：

1. **编号体系**：多级编号连续、层级清晰，`一、（一）1.（1）` 顺序不得混用错层。
2. **对齐**：同级标题对齐方式一致；正文首行缩进统一。
3. **字号**：同一层级标题字号一致；正文与标题区分明确。
4. **称谓**：全文对同一主体的称谓必须统一（不得"申请人/甲方/原告"混用）。
5. **引用**：引用法律用全称+条文号，引用规则用机构名+规则名+条款号。
6. **数字与金额**：同一文书中金额单位、大小写、币种表述一致。

> 这六项是文书核阅的高频扣分项，生成与核阅时逐条自检。

## 特别说明：裁决书模板

裁决书结构与核阅要点由 `arb_award_review` Skill 承载（见 `src/aiarb/agents/skills/arb_award_review-zh/`）。
本目录只放**结构模板**，核阅方法论放在 Skill 中，避免两处维护。

## 采集纪律

1. 优先采用机构官方发布的文书范本；无官方范本时，用脱敏后的实际文书抽象结构。
2. **不得**整篇复制受版权保护的实务书籍或他人成果模板。
3. 每份入库在 `../SOURCES.md` 台账登记。
