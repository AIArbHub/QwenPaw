> **核阅方法论 v1.6**：
> - 裁决书的事实认定和裁判说理**必须由仲裁庭完成**

## 仲裁程序

> **结构**：按时间顺序陈述程序节点，**每一步都需有依据**。

### （一）申请与受理
- ____ 年 __ 月 __ 日：申请人提交仲裁申请书。
- ____ 年 __ 月 __ 日：仲裁委员会决定受理，案号 __________。

### （二）组庭

- ____ 年 __ 月 __ 日：仲裁庭组成。

- ____ 年 __ 月 __ 日：被申请人提交答辩状。

## 仲裁庭意见

> **核阅重点**：法律论证与裁判说理必须严谨完备。
> - 引用《仲裁法》而非《民事诉讼法》（程序性事项除外）
> - 每项请求→法律规定→适用本案事实→结论
> - 争议焦点的逐一回应

### （一）关于法律适用
> 根据《中华人民共和国仲裁法》第三条、第五十一条之规定，仲裁庭根据事实，符合法律规定，公平合理地解决纠纷。

> 当事人对适用法律未作约定。**根据《__________ 仲裁规则》第 __ 条之规定，由仲裁庭决定本案实体应适用的法律。** 本案争议为 __________ 合同纠纷，仲裁庭认为应当适用**中华人民共和国法律**（或：__________ 法）作为处理本案争议的准据法。

## 裁决主文

> **核阅重点**：裁决主文是裁决书的核心，必须**明确、具体、可执行**。
> 实务中常见错误：金额错误、表述模糊、超裁或漏裁。

```
根据《中华人民共和国仲裁法》及相关法律规定，仲裁庭裁决如下：

（一）__________；

（二）__________；

（三）__________；

（四）本案仲裁费人民币 __________ 元，由 __________ 承担。仲裁费已由 __________ 预交，__________ 应于本裁决送达之日起 __ 日内将应承担的仲裁费支付给 __________。

（五）申请人的其他仲裁请求 / 反请求，本仲裁庭不予支持 / 予以驳回。

本裁决为终局裁决，自作出之日起生效。
```

> 涉外裁决增加："本裁决是终局的，对各方当事人均有约束力。任何一方当事人可以依据《承认及执行外国仲裁裁决公约》（1958，纽约）或其他适用的国际条约，向有管辖权的法院申请承认和执行。"

## 裁决书核验清单（核阅方法论 v1.6）

### 形式核验
- [ ] 标题规范（机构名 + "裁决书"）
- [ ] 案号正确
- [ ] 当事人信息完整（名称、住所、法定代表人）
- [ ] 仲裁庭组成信息完整
- [ ] 程序节点完整（受理、组庭、答辩、开庭、调解、裁决）
- [ ] 仲裁员签字 / 仲裁机构印章

### 内容核验
- [ ] 申请人的仲裁请求完整归纳
- [ ] 被申请人的答辩意见完整归纳
- [ ] 事实认定逐项有证据支撑
- [ ] 法律论证引法条（仲裁法、民法典相关条款）
- [ ] 争议焦点逐一回回应
- [ ] 裁决主文明确、具体、可执行
- [ ] 仲裁费用分摊合理
- [ ] 没有超裁（裁决事项在仲裁协议范围内）
- [ ] 没有漏裁（申请人请求逐项回应）
- [ ] 没有矛盾（程序部分与实体部分、事实认定与裁决主文）

### 引用规范
- [ ] 法律全称首次出现：全称（如"《中华人民共和国民法典》"），再次出现：简称（如"《民法典》"）
- [ ] 仲裁法引《仲裁法》，不引《民事诉讼法》（除非必要）
- [ ] 法规全称与发文字号匹配

### 当事人诉请与事实证据三组交叉核对
- [ ] 申请人称 ↔ 申请材料
- [ ] 被申请人称 ↔ 被申请人材料
- [ ] 仲裁庭认定 ↔ 双方主张和证据
