# 仲裁代理词（代理意见）模板

> **使用说明**：代理词是开庭/庭后向仲裁庭系统阐述己方观点的核心文书。本模板为**论证骨架**。
> **核阅方法论 v1.6**：案件事实、证据、法律结论由代理人负责；AI 协助归纳与表述优化，**不得生成结构化数据**（案号、金额、日期、程序节点）。

---

## 一、首部

```
案号：（20XX）XXX 字第 ______ 号
申请人：__________
被申请人：__________

关于申请人与被申请人 __________ 纠纷案
代理词（代理意见）

尊敬的仲裁庭：

__________ 律师事务所接受 __________（申请人/被申请人）的委托，指派本律师担任其与 __________ __________ 纠纷一案的仲裁代理人。现根据庭审情况和本案事实，发表如下代理意见，供仲裁庭参考。
```

---

## 二、正文结构

> 核心原则：**先结论后论证**。仲裁庭时间有限，把最重要的判断放在最前面。

### （一）前置：本案争议焦点归纳

> 开宗明义归纳焦点，让仲裁庭迅速抓住脉络。一般 2-5 个。

本案的争议焦点可以归纳为：

1. __________（如：涉案合同是否有效/是否已解除）
2. __________（如：被申请人是否构成违约）
3. __________（如：损失金额如何认定/违约金是否过高）

### （二）逐一论证（每个焦点独立成节）

#### 焦点一：关于 __________

**1. 我方主张**

__________（一句话结论）

**2. 事实依据**

- ____ 年 __ 月 __ 日，__________（事实 + 证据编号，如"证据 3 第 2 页"）
- ____ 年 __ 月 __ 日，__________
- __________

**3. 法律依据**

依据《中华人民共和国民法典》第 __________ 条之规定："__________"（条文原文）。/ 依据《__________ 仲裁规则》第 __ 条之规定。

**4. 适用分析（把事实套进法律）**

本案中，__________（事实）符合该条规定的 __________ 要件，故应当认定为 __________。

**5. 对方观点的回应**

对方主张 __________，但该主张不能成立，理由如下：
- 其一，__________（事实层面反驳，指出证据矛盾）
- 其二，__________（法律层面反驳，指出依据错误）
- 其三，__________（逻辑层面反驳，指出推论跳跃）

**6. 小结**

综上，请求仲裁庭认定 __________。

#### 焦点二：关于 __________
（同上结构）

#### 焦点三：关于 __________
（同上结构）

### （三）综合性意见（可选）

> 对全案作整体评价，常用于强调公平、诚信、交易安全等价值层面。

此外，代理人恳请仲裁庭注意：__________（如：本案交易背景、行业惯例、双方履约实际、利益平衡）。

```
综上所述，代理人认为：

1. __________；
2. __________；
3. __________。

恳请仲裁庭依法支持（申请人/被申请人）的仲裁请求 / 依法驳回申请人的仲裁请求，维护（申请人/被申请人）的合法权益。

此致

__________ 仲裁委员会

代理人：__________
__________ 律师事务所
____ 年 __ 月 __ 日
```

## 四、写作要点（自检用）

### 论证质量
- [ ] **先结论后论证**，每个焦点首句即给出判断
- [ ] 每个事实陈述**标注证据编号**（可追溯到具体页码）
- [ ] 法律论证链条完整：**证据 → 事实 → 法律 → 结论**
- [ ] 对对方每个核心观点都有**针对性回应**（不回避）
- [ ] 焦点之间**不重复、不矛盾**

### 引用规范（关键）
- [ ] 仲裁程序事项引《仲裁法》与**机构规则**，**不引《民事诉讼法》**（民诉法仅在撤销/不予执行/保全/执行阶段援引）
- [ ] 引用法条**核对现行版本**（如仲裁法 2025 修订、民法典、民间借贷 LPR 4 倍）
- [ ] 引用格式符合 `CITATION.md`
- [ ] 法律全称首次出现，之后可用简称

### 表述风格
- [ ] **不堆砌法条**：引一条说透，胜于引十条不解释
- [ ] **不用空话**："综上所述请求依法裁决"这类无信息量的句子尽量删
- [ ] 称谓全文统一（不"申请人/甲方"混用）
- [ ] 金额单位、大小写、币种一致，计算可复算

### AI 合规（若在起草中使用了 AI）
- [ ] 引用的判例/法条已回源核实（见 `legal_ai_disclosure`）
- [ ] 无可核实的判例一律删除，未保留"疑似 AI 编造"的引用

## 五、常见的论证缺陷（避坑）

| 缺陷 | 表现 | 改进 |
|---|---|---|
| 只讲事实不讲法律 | 大段陈述经过，无条文支撑 | 每个事实后紧跟法律评价 |
| 只引法条不分析 | 罗列条文后直接下结论 | 补"本案符合该条 XX 要件"的分析 |
| 回避对方核心观点 | 只讲自己，不回应对方 | 逐条回应，指出其矛盾/依据错误 |
| 焦点散乱 | 一节里混杂多个问题 | 一焦点一节，标题即判断 |
| 情绪化表述 | "对方恶意违约""毫无诚信" | 改为客观行为描述 + 法律评价 |
| 请求与论证脱节 | 前面论证 A，结论突然要 B | 结论严格对应已论证内容 |
