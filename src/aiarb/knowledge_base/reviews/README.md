# 要件审查规则库

本目录存储各案件类型的六段式审查要点规则，作为 `case_frameworks.db` 的 Markdown 参考补充。

## 目录结构

```
reviews/
├── contracts/          # 合同纠纷审查要点
│   ├── 买卖合同.md
│   ├── 借款合同.md
│   ├── 建设工程.md
│   └── ...
├── corporate/          # 公司纠纷审查要点
│   ├── 股权转让.md
│   ├── 公司治理.md
│   └── ...
├── civil_tort/         # 侵权纠纷审查要点
│   ├── 人身损害.md
│   ├── 财产损害.md
│   └── ...
├── labor/              # 劳动争议审查要点
│   ├── 劳动合同.md
│   ├── 工伤赔偿.md
│   └── ...
├── ip/                 # 知识产权审查要点
│   ├── 著作权.md
│   ├── 商标权.md
│   └── ...
└── README.md           # 本文件
```

## 文件格式

每个审查要点文件使用以下格式：

```markdown
# [案件类型]审查要点

## 第2部分：立案审查
### 审查要点：[名称]
- **审查内容**：...
- **注意事项**：...
- **法律依据**：...

## 第3部分：申请人请求的审查
...

## 第4部分：被申请人抗辩的审查
...

## 第5部分：要件事实审查和裁判规则
...
```

## 数据来源

- 主要来源：实务经验总结
- 参考来源：上海法院类案办案要件指南（方法论参考，不直接复制）
- 法律声明：所有内容仅供参考，不构成法律意见
