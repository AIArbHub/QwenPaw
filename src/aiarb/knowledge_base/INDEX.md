# 共享知识库（Shared Knowledge Base）

本目录是**项目内所有智能体共享**的知识库来源，不受单个智能体工作区的限制。
智能体在回答涉及**法条、仲裁规则、案例、文书模板**等专业问题时，应优先调用
`search_knowledge` 工具检索本知识库，**不得凭空编造法条或规则**。

## 规范文档（先读）

| 文档 | 作用 |
|---|---|
| [SCHEMA.md](SCHEMA.md) | **文档头规范**——所有入库文件必填字段，缺来源不入库 |
| [SOURCES.md](SOURCES.md) | **来源与版权边界**——什么能收、什么不能收、登记台账 |
| [CITATION.md](CITATION.md) | **引用与防幻觉规则**——怎么引、标注粒度、冲突处理 |

## 目录结构

| 目录 | 用途 | 采集清单 |
|------|------|---|
| `laws/` | 仲裁法及相关法律、司法解释、国际公约 | [清单](laws/README.md) |
| `rules/` | 主要仲裁机构规则（CIETAC、BAC/BIAC、SHIAC、SCIA、HKIAC、ICC、SIAC 等） | [清单](rules/README.md) |
| `cases/` | 案例库（脱敏后的争议焦点与裁判要旨） | [清单](cases/README.md) |
| `templates/` | 文书模板库（申请书、答辩书、裁决书、程序令等） | [清单](templates/README.md) |

## 使用说明

- 首次启动时，安装包内置的初始内容会被复制到全局知识库目录
  `~/.aiarb/knowledge_base/`（可通过 `AIARB_WORKING_DIR` 改变位置）。
- 用户可直接在该全局目录下新增或修改文档；升级不会覆盖已有文件。
- 也可以通过 `config.json` 的 `knowledge_paths` 配置额外的只读知识库根目录，
  `search_knowledge` 会按顺序检索全局目录与这些额外根目录。

## 三条硬规则

1. **无来源不入库**：每个文件必须有 `source` + `source_type` + `retrieved`。
2. **不凭记忆生成**：不得编写法条、规则条文、案号、裁判要旨。检索不到就如实说明。
3. **用户材料不出域**：用户上传的案件材料只进私有工作区，脱敏后才可入共享库。

## 文档格式建议

- 优先使用 Markdown（`.md`）或纯文本（`.txt`），便于关键词检索。
- 文件名与标题尽量包含规范名称、机构名称、年份与主题，例如
  `rules/CIETAC-仲裁规则-2024.md`、`laws/中华人民共和国仲裁法-2017.md`。
- 每份文档开头按 [SCHEMA.md](SCHEMA.md) 写明：来源、机构、版本/施行日期、适用地域。
