# 共享知识库（Shared Knowledge Base）

本目录是**项目内所有智能体共享**的知识库来源，不受单个智能体工作区的限制。
智能体在回答涉及**法条、仲裁规则、案例、文书模板**等专业问题时，应优先调用
`search_knowledge` 工具检索本知识库，**不得凭空编造法条或规则**。

## 目录结构

| 目录 | 用途 |
|------|------|
| `laws/`      | 仲裁法及相关法律（如《中华人民共和国仲裁法》等） |
| `rules/`     | 主要仲裁机构的仲裁规则（CIETAC、BAC/BIAC、SHIAC、HKIAC、ICC、SIAC 等） |
| `cases/`     | 案例库（典型仲裁案例、裁判要旨、争议焦点整理） |
| `templates/` | 文书模板库（仲裁申请书、答辩书、裁决书、程序令等） |

## 使用说明

- 首次启动时，安装包内置的初始内容会被复制到全局知识库目录
  `~/.aiarb/knowledge_base/`（可通过 `AIARB_WORKING_DIR` 改变位置）。
- 用户可直接在该全局目录下新增或修改文档；升级不会覆盖已有文件。
- 也可以通过 `config.json` 的 `knowledge_paths` 配置额外的只读知识库根目录，
  `search_knowledge` 会按顺序检索全局目录与这些额外根目录。

## 文档格式建议

- 优先使用 Markdown（`.md`）或纯文本（`.txt`），便于关键词检索。
- 文件名与标题尽量包含规范名称、机构名称、年份与主题，例如
  `rules/CIETAC-仲裁规则-2024.md`、`laws/中华人民共和国仲裁法-2017.md`。
- 每份文档开头建议写明：来源、机构、版本/施行日期、适用地域。
